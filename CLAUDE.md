## Продукт

PsyCont (не PsyContent) — AI-сервис для русскоязычных психологов: генерация контента для блога (посты, карусели, Reels-сценарии, хуки, контент-план) в голосе пользователя, чтобы привлекать клиентов.

Центр продукта: «звучит как ты». Учимся на голосе пользователя, пишем как живой психолог, а не как нейросеть. Это не одна из фич, а главный ответ на главную боль рынка (генерический AI-текст не цепляет).

## Позиционирование (актуальное, пересмотрено 26 июня)

Старое «блог без выгорания» (боль усталости) больше НЕ главное.

Новая главная боль острее: психолог хочет клиентов через блог, пробовал вести, но ничего не залетает и клиенты не приходят. Это не про усталость, а про бессилие — «не понимаю, что делаю не так».

Продаём НЕ как «сэкономит силы», а как «наконец сработает и приведёт клиентов».

Целевой человек для всего копирайта: психолог 2-5 лет практики, пробовал вести блог, постил без отклика, клиентов из блога нет. Писать для него одного.

Дифференциатор: PsyCont пишет как живой психолог, а не как очередная нейросеть (нейротекст видно, он не залетает). Подавать через результат («звучит как живой человек, поэтому работает»), не через комфорт.

North Star: число психологов, публикующих 4+ поста в месяц. Цель выручки: 100к руб/мес (~33 платящих).

## Контент (генерация)

Все генерации сверять с рабочими документами: ЯДРО-ФОРМАТОВ (главный), БАНК-ФОРМАТОВ, ПРАВИЛА-ХУКОВ, ПРОМПТЫ-ГЕНЕРАЦИИ.

Что в документах:
- ЯДРО-ФОРМАТОВ: демо-психолог, типы хуков, структуры форматов, роли постов.
- БАНК-ФОРМАТОВ: структура каждого формата по блокам, когда использовать, под какую цель (охват/доверие/запись), на какой сигнал работает (досмотр/пересылка/сохранение).
- ПРАВИЛА-ХУКОВ: типы хуков с механикой, выбор под тему и площадку (рилс и ТГ хуки разные).
- ПРОМПТЫ-ГЕНЕРАЦИИ: промпт-схемы для движка.

Топ рабочих хуков (из разбора 71 рилса): цитата внутреннего голоса зрителя (зеркало, не диагноз), антихук, адресация по ярлыку-идентичности, незакрытый гештальт, признание беспомощности/антипродажа.

ГЛАВНОЕ правило генерации (не нарушать): продукт НЕ выдаёт готовые фразы из разборов. Живые формулировки — только как принципы и паттерны для few-shot, не клонировать. Иначе у всех психологов одинаковый контент.

Правила текста: показывать, а не анонсировать тему; писать для одного человека; хук сразу сценой. НЕ использовать «это не про X, это про Y», приклеенные концовки, английские кальки, объявление темы вместо крючка. Без тире. Заголовки до 6 слов.

CTA: НЕ в каждом посте. Большинство постов — чистая ценность без призыва. Роли постов в пропорции охват/доверие/запись примерно 60-70/20-30/10.

Хук решает половину: первая строка / первые 2-3 секунды / первый слайд цепляют через узнавание. Хук искренний, не фальшивый.

## Деньги (энергия и тарифы)

Текст безлимит на всех платных (скрытый честный потолок ~300/мес, пользователю не виден). Энергией метрится только дорогое: AI-картинки к каруселям и глубокий анализ конкурента. Транскрибацию голоса энергией НЕ считаем (решение 30.09): Whisper свой и почти бесплатный, а голос главный источник живой речи для обучения, платный голос = психолог перестает говорить.

Тарифы. Технический code НЕ трогать, меняются только видимые имена:
- code free → «Старт», 0 ₽ (бесплатный вход, 10 проб текста, разовые пробы: 1 карусель со своими фото, 1 проба AI-картинки, 1 проба анализа)
- code start → «Блог», 990 ₽ (текст безлимит, немного энергии, анализа нет → «доступно на Практике»)
- code practice → «Практика», 2490 ₽ (популярный, текст безлимит, больше энергии, глубокий анализ есть)
- code expert → «Студия», 4990 ₽ (всё, много энергии)
- code test → «Тест», 0 ₽ (служебный, не на витрине; безлимит, ничего не списывает, но в usage_log пишет would_charge — реальную себестоимость)

Принцип безопасности денег: пользователь только ЧИТАЕТ свой баланс/историю/тариф. Менять энергию может только сервер. usage_log и счётчик текста скрыты (только сервер). Списание атомарное (блокировка строки), в минус не уходит, при неудаче внешнего сервиса энергию не берём, журнал пишется всегда.

Энергия: месячная по тарифу сгорает, докупленная (когда будет оплата) копится отдельно. Числа энергии черновые — калибруются по реальной себестоимости (учёт токенов из ответов OpenAI пишется в usage_log).

Платёжку (ЮKassa) пока НЕ подключаем. Тариф «Тест» включается вручную через SQL по email.

## Обезличивание (152-ФЗ)

Перед отправкой в OpenAI личные данные маскируются (имена психолога и клиентов, телефоны, почты, ники, ссылки, города). Подключено во всех точках, где текст идёт в AI (включая паспорт и анализ конкурента).

Сейчас: JS-правила (lib/anonymize.ts) — широкий словарь имён, маркеры, фамилии по суффиксам, отчества, контакты, имя психолога из профиля гарантированно. Предел: редкие имена клиентов в свободном тексте без маркера просочатся.

ОБЯЗАТЕЛЬНО к запуску: spaCy (ru_core_news_lg) для надёжного распознавания. На живых психологах с реальными клиентами на одних JS-правилах НЕ запускаться.

## Защита от ботов (к запуску)

Перед запуском для реальных пользователей поставить защиту от ботов: российский антибот (DDoS-Guard) или капча на регистрации. Не пускать данные через западные сервисы (Cloudflare) из-за 152-ФЗ. Сейчас не ставим, пользователей нет.

## Живой язык (как убирать ИИ-шелуху) — суть дифференциатора

Продукт про «звучит как человек, а не как нейросеть». Это должна знать ЛЮБАЯ сессия, не только копирайтер. Детали и образцы живой речи — в агенте copywriter-psycont (.claude/agents/copywriter-psycont.md, раздел «Живой язык vs ИИ-литература»), тут кратко.

- Главный источник живого языка: транскрипты рилсов психологов в _знания/транскрипты-рилсов/ (устная речь с камеры, ее не подделать). Вторичный: живые ТГ-посты в _знания/живые-посты/. Сверяться с ними перед тем как писать любой текст (продуктовый или генерируемый).
- ЗАПРЕТ НОМЕР ОДИН: конструкция «не X, а Y» (и формы «это не про X, это про Y», «дело не в X, а в Y», «не просто X, а Y»). Самый частый признак нейросети. Всегда переписывать на прямое утверждение (не «дело не в лени, а в страхе», а «за откладыванием часто прячется страх»).
- Другие ИИ-маркеры: книжные абстракции и пафос («раскрыть потенциал», «безопасное пространство», «путь к себе», «обрести гармонию», «ресурсное состояние»), терапевтический жаргон в тексте для людей («остаюсь с ним в этом», «контакт с собой»), старомодные обороты («носило по волнам»), английские кальки, приклеенные концовки с моралью.
- Еще маркеры (добавлены 30.09, ловит text-guard и П4): псевдоглубина рублеными фразами («Вечер. Тишина. ## Как работаем (процесс)

- Перед каждым шагом — план простыми словами, ждать «ок». Не начинать без подтверждения.
- После шага — коммит с понятным сообщением, пуш (после проверки).
- Деньги и безопасность — двойной контроль (показать SQL/доказательства до применения).
- Изменения базы — показать миграцию на просмотр, Арина применяет сама в Supabase.
- Развилку, которой нет в ТЗ, — спросить, не решать самому.
- После шага приносить наглядные доказательства (что проверено, с результатом).
- После каждого UI-шага проверять мобильную версию (320-390px): подчёркивание, фон, пустые состояния, лого, чтобы ничего не поехало. Мобилка в чеклисте каждой UI-волны.
