# Примеры плана v2, версия 2 (после продуктового критика, 27.11)

Собраны черновым кодом по правилам: цель берется из формата; сцены идут в форматы узнавания, фразы «что говорят вокруг» в перевод и разбор фразы; строка в плане не повторяется, кончились строки главной темы: соседняя тема той же группы; маленькому 4 формата по кругу; порядок строк свой у каждого психолога. Серий, лестницы съемки и личного в первой версии нет. Запуск показан для второй версии.
