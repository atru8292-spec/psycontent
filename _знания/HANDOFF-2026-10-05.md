## 3. Что осталось и известные проблемы
- **Демо-блок лендинга снят.** Финал онбординга открывает «Сделать» с темой дня, а в `components/make/MakeFlow.tsx` стоит `initialText={initialTopic || restoreText || seed}`: тема побеждает мысль из демо (`psycont_seed_thought`), и мысль стирается без поста. Починка: при `first=1` ставить seed выше topic, или в `app/onboarding/express` на финале не подставлять тему дня, если есть свежий seed. После этого вернуть блок (код в истории, коммит d8cb004). Онбординг и «Сделать» трогать только с «да» Арины.
- **Анонимные land_* в боевой базе** от скриншотов 04.10 (локальная копия работала с `.env.local`): несколько строк `land_view` и, возможно, `land_faq_open` без user_id. Удалять только с «да» Арины.
- **12 старых ошибок tsc в main** (components/content-plan-display.tsx 2, utils/supabase/middleware.ts 6, utils/supabase/server.ts 4), их прячет `ignoreBuildErrors: true`. Правило: новых ошибок относительно main быть не должно.

## 4. Правила, на которые наступали
- `npm run build` только в отдельном git worktree (`git worktree add ../psy-check main`), никогда в основной папке: там работает dev Арины на 3005, сборка ломает его `.next`. Временный `.env.local` в копии удалить перед удалением worktree.
- Локальная сборка с `.env.local` ходит в боевую базу: скриншоты снимать с заблокированным `/api/ev`.
- Для локальной разработки в `.env.local` нужен `SITE_URL=http://localhost:3005`, иначе `publicOrigin` на localhost уводит вход и редиректы на https://psycont.ru.
- Редиректы и адреса только через `publicOrigin`, в middleware без `rewrite` (за nginx Next проксирует сам к себе).
- Скриншоты лендинга снимать без входа (Playwright): залогиненного лендинг уводит в /dashboard.
- Новый файл в `public` или новая SECURITY DEFINER функция: смотреть разделы граблей в CLAUDE.md.
