## 61 — «Угадайте тип клиента (64 часть)» — курение/иллюзия контроля

**ТЕМА:** симуляция онлайн-сессии, клиент сам осознаёт причину зависимости от курения. **ТИП:** split-screen Zoom-сессия, серийный «угадайте тип».

**ХУК.** «Угадайте тип клиента (64 часть)». Механики: **«угадайте» = прямое вовлечение** (из пассивного просмотра в игру, мозг принимает задание); «64 часть» = соц.доказательство + сериальность; «тип клиента» = две аудитории (психологи проверяют классификацию + клиенты узнают свой тип).

**ФОРМАТ.** Симуляция терапевтической онлайн-сессии + вовлекающий вопрос. Постановочная сценка под скриншот видеозвонка, без дидактики/вывода — зритель интерпретирует сам.

**СТРУКТУРА:** заголовок-якорь весь ролик → психолог «с чем пришли?» → монолог клиента (7 лет курения, ковид/военные события, инсайт «дым — то, чем могу управлять») → краткая реакция «очень интересное наблюдение» (максимум пространства клиенту) → клиент сам формулирует решение → финал без «правильного ответа», клиент «бросаю сегодня, горжусь собой».

**РАЗБОР ТЕКСТА.** «Ой, я тут поняла» = снимает скрипт. «Эти всякие военные события» = не углубляется в травму (психологически точно). «Дым — то, чем могу управлять» = **иллюзия контроля простым языком без терминологии**. «Бросаю сегодня, горжусь собой» = клиент уходит сам → **демонстрация хорошей терапии (сопровождение, не директива) = реклама без рекламных слов.**

**ВИЗУАЛ.** Split-screen Zoom (психолог в гарнитуре / клиент), тёмные фоны убирают шум. Заголовок статичен весь ролик (удержание фрейма). Финал — обе улыбаются (катарсис). Спокойный темп = «подслушиваю настоящую сессию».

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Split Zoom = знакомый формат, «я в комнате». «Угадайте» = когнитивное вовлечение (строит гипотезу, не скроллит). Монолог про контроль/ковид = узнавание. Финал «горжусь собой» = дофаминовый укол. **Незакрытый гештальт (ответ не дан) → пишут версию в комменты.**

**МЕХАНИКА ЗАЛЁТА.** Досмотр — диалог + задание. Комменты очень высокие («угадайте» = прямой призыв). Пересылка «вот как это изнутри» (снимает страх перед психологом). **Слабое место: ответ на «какой тип» не даётся** (для новых фрустрирующе).

**ЧТО БЕРЁМ В PSYCONT:**
1. **Серийный формат с нумерацией** («64 часть» = архив + лояльная база, идут смотреть предыдущие).
2. **Вопрос «угадайте» как движок комментариев** (не продаёт — предлагает проявить экспертизу/опыт).
3. **Двойной экран онлайн-сессии** (контекст за секунду).
4. **Скрытый маркетинг через демонстрацию работы** (результат процессом, не утверждениями).
5. **Одна цитируемая формулировка** на ролик (зритель запоминает идею, привязанную к автору).

## 62 — «Всё, у меня нахрен крик души» (психолог vs блогер)

**ТЕМА:** внутренний конфликт «я психолог / я не блогер». **ТИП:** говорящая голова, ночная улица, один дубль.

**ХУК.** «Всё, у меня нахрен крик души». Три механизма: **мат от психолога в первую секунду** (нарушение ожидания «спокойный, терминами»); «крик души» = обещание настоящего, не экспертного поста; «всё» = точка невозврата («долго держался, прорвало»).

**ФОРМАТ.** Признание/исповедь, поток внутреннего голоса, один дубль на улице. «Думать вслух публично» — материал сырой, незаконченный.

**СТРУКТУРА:** 1) «Я психолог. Я не блогер» (противоречие = хук внутри хука); 2) контекст (двор, кофейня — реальный человек); 3) **«у меня нет контентного мышления, у меня критическое»** (оправдание сопротивлению); 4) раздвоение цели (транслировать себя / делать по канонам) без ответа; 5) психологический тезис («избавиться нельзя, нужно соединять части» — прорастает профессиональное); 6) открытый вопрос «задача найти баланс»; 7) «эго раскричалось. Всем пока» (незавершённость).

**ВИЗУАЛ.** Ночной Петербург, мокрый асфальт, отражения вывесок, один непрерывный план, без света/стабилизатора. Телефон в руках («спонтанно, сейчас»). Мимика широкая (улыбается на «критическое», тревога/растерянность дальше, закрытая поза в финале). Субтитры-маяки. **Антипродакшн как приём: «это не контент, это жизнь» — форма доказывает тезис (она не блогер).**

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Мат → палец не листает. «Я психолог, я не блогер» → коллеги/специалисты с блогом «это про меня». Ждёт разрешения конфликта (не выносит незакрытого гештальта) — нет → держит до конца. Финал без вывода → желание прокомментировать (поддержать/посоветовать/поспорить). **Идентификация через стыд** («нет контентного мышления» названо без самобичевания → легче).

**МЕХАНИКА ЗАЛЁТА.** Досмотр — незакрытый конфликт. Комменты почти гарантированы (дописывают за автора). Пересылка нишевая (психологам «это про нас»). Сохранение маловероятно (нет инструмента).

**ЧТО БЕРЁМ В PSYCONT:**
1. **«Признание в прямом эфире жизни»** (один дубль, настоящий нерешённый конфликт).
2. **Хук через нарушение профессионального образа** (психолог говорит неожиданное).
3. **«Я не знаю» как позиция** (специалист публично не знает → сильный контакт).
4. **Один непрерывный план без монтажа** (склейка разрушит спонтанность).
5. **Открытый финал** как механика комментариев.
6. **Ограничение:** не работает как воронка (строит доверие, не ведёт к записи).

## 63 — «Самопожертвование → ненависть» (цитата Бернарда Шоу)

**ТЕМА:** самопожертвование в отношениях порождает ненависть к тем, ради кого жертвуешь. **ТИП:** разбор через цитату, разделённый кадр.

**ХУК.** Цитата Шоу «Если начинаете с самопожертвования ради тех, кого любите, закончите ненавистью…». Три механизма: **спор/диссонанс** (жертва = добродетель + «ненависть» = разрыв ожидания «как связано?»); **цитата авторитета** (снимает ответственность за провокацию, повышает вес — споришь с классиком, не психологом); личное узнавание (попадает в подавленное чувство, которое не разрешал называть).

**ФОРМАТ.** Разбор-объяснение через цитату. Говорящая голова + параллельный текст. Разбор одного тезиса от хука до практического вопроса.

**СТРУКТУРА:** 1) хук-цитата («ненависть» висит весь ролик = якорь); 2) **снятие обвинения** «большинство не планируют ненавидеть, искренне хотят любить» (безопасность → продолжает); 3) механизм «он фиксирует: после всего, что я делаю, ты должен ценить» (прямой внутренний монолог); 4) точка зрения второй стороны (не просил, чувствует давление, дистанцируется); 5) итог «я столько сделал, а ты» → «приходит ненависть» (возврат к хуку); 6) культурный контекст («любовь = стирание границ» романтизируется → снижает стыд); 7) практический выход (2 вопроса: нужно ли близкому то, чем жертвуете; что ждёте взамен).

**ВИЗУАЛ.** **Разделённый кадр** (верх — лицо, низ — тёмно-зелёный фон с текстом): без звука читается полный текст, со звуком — двойное восприятие. Левая колонка зафиксирована (цитата весь ролик = якорь). Петличка (по-человечески). Бытовая эстетика (нет офиса/дипломов).

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** 0–3с диссонанс «жертва+ненависть». 3–15с «не планируют ненавидеть» → облегчение (нет осуждения). 15–40с внутренний монолог «после всего, что я делаю» = **«меня раскрыли»** (носят годами, не признаваясь). 40–60с точка зрения второй стороны (впервые). Финал — 2 вопроса-самодиагностика → сохранить/вернуться.

**МЕХАНИКА ЗАЛЁТА.** Тема легализует стыдное чувство (ненависть к близким) через цитату+механизм. Пересылка (думает о конкретном человеке). Сохранение (вопросы не отвечены). Досмотр — параллельный текст держит (читает всё). Спорность → комменты.

**ЧТО БЕРЁМ В PSYCONT:**
1. **«Цитата известного человека + разбор механизма»** (цитата снимает сопротивление, разбор даёт глубину).
2. **Разделённый кадр** (лицо сверху, текст снизу) — досмотр без звука.
3. **Прямая речь внутреннего монолога** («после всего, что я делаю») > описания от третьего лица.
4. **«Снятие обвинения перед объяснением механизма»** (безопасность до узнавания себя в негативном паттерне).
5. **Финал-вопрос к себе** вместо CTA (мягкий вход в воронку).
6. Темы — романтизируемые, но разрушающие паттерны (жертвенность, спасательство, слияние).

## 64 — «Как меня учили работать с депрессией» (идеал vs реальность сессий)

**ТЕМА:** как КПТ-психолог работает с депрессией на практике (1→20 сессия) vs учебник. **ТИП:** съёмка экрана Google Meet-сессии + закадровый голос + счётчик сессий.

**ХУК.** «Как меня учили работать с депрессией» поверх экрана MacBook с Meet + «1 сессия» + сразу по делу «подозреваю депрессию, сходи к психиатру». Три триггера: **«учили» переключает фрейм** (ждёшь теорию — попадаешь в живую сессию); «как меня учили» = скрытое противопоставление (мозг достраивает «…а в реальности иначе»); **Google Meet как визуальный хук** («подглядываю за настоящей работой»).

**ФОРМАТ.** Параллельный монтаж «идеал vs реальность» с таймлайном сессий. Закадр поверх B-roll рабочего процесса, нарастающий счётчик.

**СТРУКТУРА:** блок «как учили» (академический протокол КПТ: психиатр → поведенческая активация → убеждения → к 20-й значительное улучшение, весь маршрут в один блок) → блок «реальность» (счётчик поштучно 1/2/10/13/15/17/18/20, живые реплики: «тебя не поставят на учёт», «к психиатру ходят не только психи», «называешь себя ленивой, а может это депрессия?», «просто заняться делом не лечит депрессию») → финал «важно признать, что депрессия есть». **Арка: теория — протокол; реальность — первые 15+ сессий на то, чтобы человек поверил, что болен.**

**ВИЗУАЛ.** Съёмка экрана ноутбука с Meet (камера сверху-сбоку) = **«двойное окно»** (психолог через ноутбук + клиентка в Meet) = подлинная рабочая ситуация, не «для Instagram». Навигация: сверху «как учили / реальность», снизу номер сессии (читается без звука). Нарочитая «некрасивость» = маркер подлинности. Лицо клиентки весь ролик (живой человек, не теория).

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Поток 1 (с депрессией): узнавание реплик из своего опыта («не просто ленивая») → сохранение «покажу маме, который думает, что я ленюсь». Поток 2 (психологи): честный разрыв учебник/практика → «так точно». **Психообразование в форме драмы** (живая сцена вместо «5 признаков»). Нормализация страха психиатра. Счётчик = крючок (хочется дотянуть до 20).

**МЕХАНИКА ЗАЛЁТА.** Досмотр — нарастающий счётчик. Пересылка в обе стороны (близким / коллегам). Сохранение как «легитимация состояния». Виральный множитель — стигма психиатра/«учёта».

**ЧТО БЕРЁМ В PSYCONT:**
1. **Формат «как меня учили vs реальность»** (горе/тревога/психосоматика — где есть разрыв учебник/практика).
2. **Счётчик как структура** (нумерация сессий/дней создаёт интерес без интриги).
3. **«Экран ноутбука + онлайн-сессия»** (нулевой порог производства + максимум подлинности).
4. **Психообразование через сцену, не объяснение** (показывай психолога за работой, не объясняющего работу).
5. **Нормализация страхов через конкретные реплики** («к психиатру ходят не только психи»).
6. **Без CTA** (финал на смысловой точке → доверие через демонстрацию компетентности).

## 65 — «Такие просмотры хотите?» (формат «открытые вопросы» для психологов)

**ТЕМА:** как психологу использовать формат «открытые вопросы» для роста. **ТИП:** говорящая голова + оверлей-скриншоты аналитики.

**ХУК.** Скриншот аналитики (108K просмотров, 1.7K сохранений; за 60 дней: 640K просмотров, +4037 подписчиков) + «Такие просмотры хотите? А столько подписчиков хотите?». **Соц.доказательство через цифры** (психолог с 50–500 подписчиками отвечает «да, хочу» внутри). Конкретные цифры > слов = доверие + зависть. Сразу факт без «привет, я расскажу» = стопор скролла.

**ФОРМАТ.** Разбор-совет / мета-контент (психолог психологам про блог). Мини-инструкция: проблема (низкие охваты) → решение (формат) → примеры → механика → CTA с лид-магнитом.

**СТРУКТУРА:** хук цифрами → обещание («недооценённый формат, легко повторить» — низкая конкуренция + снятие сопротивления) → называет формат («открытые вопросы» = категория знания) → шаг 1 (скрипт «это вопрос от психолога / психологический тест») → шаг 2 («глубокий вопрос без однозначного ответа») → 3 примера (разнокалиберные: «что сказать маме» глубокий + суперспособности/$1млн лёгкие = диапазон) → механика («привлекает рефлексирующую аудиторию», «клиенты приходят, когда доверяют» — вскользь, без нажима) → CTA (Dadre.ru/formats + слово «статья» в комменты).

**ВИЗУАЛ.** Картинка не меняется (белая футболка, домашний фон, петличка BOYA). Динамика: **реальные скриншоты аналитики поверх видео** (не нарисовано → факт, не обещание) + субтитры с укрупнением + таблички-метки темы + финальная табличка с адресом. Домашний свет = «человек говорит напрямую», снижает рекламное давление.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** ЦА: психолог с блогом, боль «снимаю, смотрят 200, подписываются единицы». Триггеры: зависть+любопытство («обычная женщина без студии — если она смогла…»); низкий барьер («недооценённый», «легко»); **примеры работают двойственно** (скрипт для психолога + зритель сам отвечает «что бы я сказал маме» → видео само пример формата); «клиенты приходят, когда доверяют» вскользь = правда, не продажа; слово в комменты = механика алгоритма.

**МЕХАНИКА ЗАЛЁТА.** Досмотр — пошаговость, новый элемент каждые 5–7с. Сохранение — 3 готовых скрипта. Комменты — «напишите слово». Пересылка нишевая (коллегам). **Видео само является демонстрацией своей темы** (мета-уровень).

**ЧТО БЕРЁМ В PSYCONT:**
1. **«Статистика в кадре как хук»** (реальный скриншот аналитики = стоп-скролл для коллег/интересующихся).
2. **Формат «открытый вопрос»** (хук «вопрос от психолога» + один вопрос без ответа + работа в комментах — дёшево, даёт вовлечение).
3. **Механика «ключевое слово в комментарии»** (CTA + триггер алгоритма).
4. **Мета-позиция «о нас» (психологах), не «о себе»** (снижает барьер доверия).
5. **«Клиенты приходят, когда доверяют»** как проходная мысль в середине (осядет лучше слогана).
6. **Визуальная простота как осознанный выбор** (намеренно, не «нет оборудования»).
