## 36 — «Если ты это не понимать, тобой легко управлять» (флипчарт + baby-talk)

**ТЕМА:** как перестать бояться негативных мыслей («бабаек») — через метафору + схему на флипчарте, в ответ на комментарий. **ТИП:** реакция на комментарий + флипчарт + baby-talk.

**ХУК.** Скрин комментария «Если я даже боюсь послать нахуй мысли-бабайки, что делать?» + плашка «ЕСЛИ ТЫ ЭТО НЕ ПОНИМАТЬ, ТО ТОБОЙ ЛЕГКО УПРАВЛЯТЬ:» + аудио baby-talk «сердечко бубо, животик бубо». Механизмы: **комментарий как зеркало** (узнаёшь себя в чужом вопросе без усилия); **угроза в заголовке** («тобой управляют» → защитная реакция → досмотр); **baby-talk с первых слов** = резкое переключение регистра (смешно + точно: тревога ощущается как детская/беспомощная).

**ФОРМАТ.** Реакция на комментарий + объяснение через флипчарт + baby-talk. Внешне «ответ подписчику», по сути мини-лекция с визуализацией.

**СТРУКТУРА:** 1) хук-комментарий + провокация; 2) диагноз на baby-talk «большие тётя-дядя тебе не сказали» (снимает вину: тебя не научили); 3) образ «добрая тётя скажет правду» (экспертность через образ, не регалии); 4) схема на флипчарте (рисуется по ходу = живое думание); 5) разрушение иллюзии «бабайки придуманные»; 6) слоган «мир не меняться, глаза меняться» (когнитивная реструктуризация в 2 слова).

**ВИЗУАЛ.** Статичная сцена у флипчарта, оранжевая стена. Схема дорисовывается красным/розовым маркером по ходу (зритель смотрит, как мысль оформляется в структуру). **Очки надеваются в середине** = сознательный твист «что это было» → удержание. Скрин комментария закреплён весь ролик (контекст «ответ на реальную проблему»). Субтитры по одному слову (ритм + помогают воспринимать baby-talk-синтаксис).

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** 0–2с идентификация через чужой комментарий. 5с baby-talk → удивление+смех → снижение защит. Середина — две дорожки восприятия (флипчарт + аудио) удерживают физически. «Бабайки придуманные» = простая формула для сложного переживания → облегчение. **Грамматически неправильная финальная фраза фиксируется в памяти лучше правильной.**

**МЕХАНИКА ЗАЛЁТА.** Досмотр — юмор+флипчарт+незавершённость схемы. Пересылка — «про моего друга» + необычный язык. Сохранение — ощущение «техники» (хотя шагов нет, только переосмысление).

**ЧТО БЕРЁМ В PSYCONT:**
1. **«Реакция на комментарий»** (скрин реального вопроса = доверие, снимает «рекламность»).
2. **Флипчарт** (схема от руки, появляется по ходу, не заготовлена).
3. **Намеренное упрощение языка** (метафора/образ вместо терминов: бабайки = автоматические мысли).
4. **Финальная фраза как «упаковка вывода»** (одна короткая, повторяемая).
5. **Бытовая эстетика** = сигнал доверия.
6. **Визуальный твист в середине** (очки/реквизит/смена ракурса) → удержание.
7. **НЕ копировать bukвально:** мат + baby-talk = личный бренд автора, без органики выглядит как «казаться».

## 37 — «5 причин выбрать меня психологом» (Паша, ноутбук + мемы)

**ТЕМА:** продающая самопрезентация психиатра-психотерапевта в мем-юморе. **ТИП:** говорящая голова + мем-слайды на ноутбуке.

**ХУК.** Ноутбук «5 ПРИЧИН, ПОЧЕМУ ВЫ МОЖЕТЕ ВЫБРАТЬ МЕНЯ» + «меня зовут Паша…». Работает не интригой, а **прямолинейным обещанием + считыванием формата** (список конечный → можно досмотреть). **«Выбрать» переключает позицию** («вы решаете», не «я продаю» → снимает сопротивление продажнику). Доп.хук: горящий предмет (чипс?) в руке = абсурдный несмысловой элемент, задерживает взгляд.

**РАЗБОР ПРИЧИН (каждая закрывает возражение):** 1) сленг (бимба/кринж + советские «хохма/получка») = «работаю с разными поколениями» → узнавание «он про меня»; 2) «врач-психиатр, а учиться на это, да хуй я» = авторитет + самоирония (доверие + убирает дистанцию); мем про суициды = проф.чёрный юмор «я психиатр»; 3) «утонуть в колодце с говном» (попросить денег) = точная телесная метафора тревоги; 4) **противопоставление** «не из тех, кто кивает… рядом, но не на стороне разрушающих привычек» (называет страх клиента + формула альянса без жаргона); 5) цена 3000 + мем «не умею считать» = снятие напряжения вокруг денег → CTA «пишите в телеграм».

**ВИЗУАЛ.** 4 слоя: говорящая голова (неглянцевая, не-продажная) + ноутбук как сцена для слайдов (детский игровой фон контрастирует с темой = юмор) + мемы (вирусные, несут заряд до просмотра, переводят тезис в образ) + горящий предмет (постоянный визуальный шум, абсурд). Ритм держится на смене слайдов, не монтаже.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Каждый пункт закрывает возражение перед первым визитом: «не поймёт» → сленг; «некомпетентен» → врач; «не подойдёт по стилю» → колодец/усталость; «будет кивать» → противопоставление; «дорого/непонятно» → цена+тг. Формат как **фильтр** (притягивает «своих», отталкивает ищущих строгого).

**МЕХАНИКА ЗАЛЁТА.** Досмотр — счётчик «5» + смена мемов. Пересылка «это ты/про нас» (мемы про усталость/контроль → тревожным). Комменты — цитирование мемов.

**ЧТО БЕРЁМ В PSYCONT:**
1. **Самопрезентация через нумерованный список закрытых возражений** (каждый пункт = «зачем именно ты»).
2. **Мем как иллюстрация тезиса** (заголовок серьёзно + мем близко = доверие+контакт).
3. **Ноутбук-экран** = мемы без монтажа (низкий порог производства).
4. **Конкретные слова-маркеры аудитории** вместо «работаю с разными».
5. **Снятие страха цены через юмор** (называть прямо + мем-контекст).
6. **Противопоставление архетипу** («я не из тех, кто кивает/молчит/даёт советы»).
7. **CTA — одно простейшее действие** (написать в тг, не форма на сайте).

## 38 — «Служба поддержки встретившихся со взрослой жизнью» (к 8 марта)

**ТЕМА:** противоречивые женские желания через скетч оператора горячей линии. **ТИП:** скетч / монолог одного персонажа в роли.

**ХУК.** «Служба поддержки встретившихся со взрослой жизнью… для женщин». «Служба поддержки» = знакомая ненавистная ситуация (колл-центр), но «встретившихся со взрослой жизнью» ломает шаблон = **гибрид боли и иронии** → «это про меня» за 3 секунды. Формат «звонок» создаёт ожидание разрешения проблемы (потом комично опрокидывается). Субтитр-якорь весь ролик.

**ФОРМАТ.** Скетч от лица оператора — слышна только одна сторона, содержание звонка восстанавливается через повтор. **Театральный приём: зритель достраивает вторую сторону и слышит в ней себя.**

**СТРУКТУРА:** заставка → серия «и…и…» (желание А + противоречащее Б, по нарастанию абсурда/узнаваемости: бизнес-вумен И содержанка; любить как есть И похудеть до 45; детокс-ретрит И вот этот бургер) → **финал-валидация** «не вижу никаких противоречий, девочки. Так и должно быть. С 8 марта, будьте собой».

**РАЗБОР ТЕКСТА.** «Оператор повторяет запрос» = снимает защиту (деловой нейтральный тон, не осуждение). **Связка «и…и…» без «но»** критична (оценка снята → финал «не вижу противоречий» = принятие, не издевательство). Разговорный необработанный язык = «писалось за 5 минут про себя» = подлинность. **Финал-валидация вместо морали** = из комедии про «женскую нелогичность» → контент про принятие себя.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Узнавание желания как своего («о нет, это я» — не стыд, юмор) → нарастающее попадание → «она поймёт» (переслать) → финал-разрядка + валидация → смех как принятие себя. **Точное попадание в то, чего хотят от психолога: признание, что противоречивые желания — норма.**

**ВИЗУАЛ.** Один кадр весь ролик, без монтажа. Весь интерес на мимике (брови, поджатые губы, закатывание глаз под каждый запрос = лицо как перкуссия). Субтитр-рамка жанра. Отсутствие монтажа = намеренная фактура «живой человек говорит правду».

**МЕХАНИКА ЗАЛЁТА.** Досмотр — список без явного конца + финал-поворот. **Пересылка — главный двигатель** (узнал себя → вспомнил подругу → «это ты»). Привязка к 8 марта = сезонное окно пересылаемости.

**ЧТО БЕРЁМ В PSYCONT:**
1. **Формат «служба поддержки / горячая линия»** как оболочка скетча («горячая линия для тех, кто хочет меняться, но не хочет ничего менять») — нейтральный тон, снимает морализаторство.
2. **Финальная валидация вместо вывода-поучения** («всё в порядке» > «вот что надо делать» — аудиторию и так завалили советами).
3. **Перечисление противоречий** под темы амбивалентности (хочу близости и боюсь; хочу меняться и остаться) с нарастанием и финальным принятием.
4. **Говорящая голова без монтажа** как осознанный выбор (если игра+текст держат).
5. **Сезонность как усилитель** (готовить ролики под даты эмоц.активности).
6. **Осторожно с гендерными стереотипами** (часть аудитории почувствует упрощение).

## 39 — «Ты же психолог: тебе не стрёмно? — Очень стрёмно, поставьте лайк»

**ТЕМА:** страх публичности у самого психолога. **ТИП:** 2 кадра, мем «вопрос/ответ».

**ХУК.** Кадр 1: «Ты же психолог… Тебе не стремно выкладывать видео в соцсети?». Механизмы: **чужой голос** (реплика зрителю-психологу → «мне так говорили / я сам себе говорю»); зашитая логика стереотипа «знаешь про психику → у тебя всё в порядке → страха нет» (триггер «наконец кто-то сказал»); «стремно» = разговорное, нулевая дистанция (не «тревога публичности»).

**ФОРМАТ.** Двухкадровый мем «вопрос/ответ» (стереотип → разрушение). Транскрипт пустой — смысл в тексте + мимике.

**СТРУКТУРА:** Кадр 1 — пишет, голова опущена (напряжение «перед ответом»). Кадр 2 — взгляд в камеру, щека на руке, «Очень стремно. Пожалуйста, поставьте лайк» (нейтральное серьёзное лицо делает шутку смешной).

**ВИЗУАЛ.** Без монтажа/графики. **Ключевой приём — смена позы** (вниз/закрыто → прямой взгляд/честно) = двухтактный ритм «ожидание/реальность». **Просьба о лайке встроена в шутку** (часть признания «мне уязвимо, поддержите»), а не CTA в подписи → работает через солидарность, не раздражает.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Двойная ЦА: психолог («это про меня» → лайк/переслать) + клиент («психолог живой, не на пьедестале» → доверие). Триггеры: «меня раскрыли»; уязвимость без нытья («очень стремно» коротко, без самокопания); просьба о лайке как разрушение 4-й стены.

**МЕХАНИКА ЗАЛЁТА.** Досмотр 100% (2 кадра). Пересылка высокая («перешли психологу» / проф.сообщества). Сохранение среднее. Лайки — редкий случай, когда прямая просьба не раздражает (встроена в уязвимость).

**ЧТО БЕРЁМ В PSYCONT:**
1. **Двухкадровый мем «стереотип о психологе / реальность»** («ты же психолог, у тебя нет тревоги» / «есть»; «ты всегда знаешь что сказать» / «нет»).
2. **Просьба о действии внутри текста на экране** (не в подписи/голосом) = снижает барьер CTA.
3. **Уязвимость без объяснений** (короткое признание без самооправдания).
4. **Нейтральная мимика на ответе** (не улыбка — делает юмор живым).
5. Тема публичности психолога = болевая точка профессии (виральность внутри сообщества).

## 40 — «Меня не понимают в интернете» (психолог по РПП)

**ТЕМА:** защита проф.позиций от хейта + манифест «люди выбирают приятную ложь». **ТИП:** жалоба-исповедь → манифест, плотные вставки (стикеры чужих видео, скрины комментариев, эмодзи, b-roll).

**ХУК.** «Кажется, меня не понимают в интернете» + плашка + вилка в руке. Механизмы: парадоксальная уязвимость (от человека, который тут же заявит о куче образований → диссонанс); «не понимают» = знакомая жалоба (узнавание); «кажется» = ирония (она не сомневается в правоте) → зритель чует противостояние, хочет узнать с кем.

**ФОРМАТ.** Жалоба-исповедь → манифест. Гибрид: исповедь («меня атакуют») → шаблон «говоришь X, получаешь Y» ×4 → манифест с позицией. Внутри — скрины реакций и стикеры чужих видео как доказательная база.

**СТРУКТУРА:** 1) хук + верификация (психолог РПП, образование, скрин профиля); 2) тезис «большинство хотят жить в иллюзии»; 3) **4 блока «говоришь — получаешь»** (тезис + стикер чужого видео с просмотрами + стопка скринов комментариев): 1500 ккал мало → «79 дней так ем»; фитнес-контент опасен при РПП → «оправдываете ленивых»; сладкое норма → «пропагандируете ожирение»; тело блогера = их образ жизни → «вы завидуете»; 4) диагноз интернету + розовый кадр «ТЫ МОЖЕШЬ ВСЁ» (сказка-антагонист); 5) биологический аргумент (мозг+ДНК+«ПЛЕВАТЬ»); 6) финал-манифест «между приятной ложью и неприятной реальностью выберу второе. Многие меня за это ненавидят».

**РАЗБОР ТЕКСТА.** «Дафига образований» вместо «многолетний опыт» = снижает пафос, «жалуется подруге». **Повтор «говоришь X — получаешь Y» ×4 = риторический молот** (превращает личную обиду в социальный диагноз — паттерн, не один комментарий). «Мне остаётся надеяться» (не «призываю») = устал биться об стену → сочувствие. Финал «многие меня ненавидят» = принятие цены → «нет, я согласна» в комментах.

**ВИЗУАЛ.** Держится на **плотности слоёв**, не эстетике. Вилка = символ еды (тема) + странность (запоминаемость). Постеры на стене («ИДЕАЛЬНО НЕЛЬЗЯ ВОВРЕМЯ») = позиционирование. Стикеры чужих видео с просмотрами = доказательная база + соц.доказательство масштаба. **Скрины комментариев внахлёст = эффект «потока хейта»**. Розовый кадр = сарказм в цвете (язык мотивационного инфоконтента, который критикует). Субтитры с крупными акцентами (досмотр без звука). Склейки каждые 2–4с.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Лагерь 1 (РПП): «наконец кто-то сказал то, что я чувствовала» → облегчение → пересылка тому, кто так говорил. Лагерь 2 (писавшие такие комментарии): дискомфорт, но спор держит → идут комментировать. **«Защита vs нападение» = нарративный двигатель досмотра.** Финал «меня ненавидят» → желание защитить автора.

**МЕХАНИКА ЗАЛЁТА.** Досмотр — высокий темп + структура «говоришь/получаешь» + субтитры без звука. Пересылка адресная (тому, кто так говорил). Сохранение — аргументы под рукой + «наконец сформулировали».

**ЧТО БЕРЁМ В PSYCONT:**
1. **Формат «говоришь X, получаешь Y» ×3–4** (создаёт ощущение системы, не жалобы): «говоришь, что граница — не эгоизм, слышишь…».
2. **Скрины реальных комментариев** как визуальный слой (доказательная база + конфликт на экране).
3. **Исповедь с позицией > лекции** (зритель присоединяется к позиции, не запоминает информацию).
4. **Финал «принятие цены»** («меня критикуют, но я не изменю позицию») = ценностная устойчивость → доверие.
5. **Реквизит как символ** (вилка в нише РПП — органичный предмет работы).
6. **Постеры на стене как часть бренда** (повторяющийся смысловой сигнал без слов).
7. **Розовый фон = ирония над конкурентным контентом** (риск: не все считают иронию).
