# Глубокие разборы reels 31–35 (маркетолог + психолог + редактор)

---

## 31 — «20 популярных форматов контента»

**ТЕМА:** список из 20 форматов контент-маркетинга + мета-твист (видео само является одним из них). **ТИП:** говорящая голова + врезки-примеры чужих видео.

**ХУК.** Титул «20 ПОПУЛЯРНЫХ ФОРМАТОВ КОНТЕНТА (для всех ниш)» + счётчик 312 тыс. Три механизма: число «20» = конкретное обещание структуры; скобка «для всех ниш» убирает «это не про меня»; скорость (называет формат → сразу пример внизу) = «тут конкретика, не рассуждения».

**ФОРМАТ.** Говорящая голова + врезки-примеры в нижней трети («живая иллюстрированная энциклопедия»). Финал — мета-твист (видео само себя иллюстрирует).

**СТРУКТУРА:** быстрое перечисление (зелёный экран → split → топ-10 → пауза/плей → доска → кино), каждый = название + пример → финал «ПОЗДРАВЛЯЮ, ВЫ ТОЛЬКО ЧТО ПОСМОТРЕЛИ ВЕСЬ СОВРЕМЕННЫЙ КОНТЕНТ-МАРКЕТИНГ ЗА 15 СЕКУНД».

**РАЗБОР ТЕКСТА.** Транскрипт = одно предложение (не объясняет — называет). Почему работает: перечисление без пауз = экспертная беглость («знает наизусть»); меньше слов = выше темп = удержание; финал «ты это сделал и не заметил» = момент инсайта → переслать. «Поздравляю» = лёгкий юмор + покровительственность = запоминаемость.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** 0–2с «мне нужно знать, досмотрю» (внутренняя задача). В процессе — **эффект ярлычка** (хаотичный опыт «видел похожие» → структура «а, это называется…»). Счётчики во врезках = соц.доказательство. Финал = «ах вот оно что» → восхищение → переслать «смотри как сделано». Доп.слой: контентмейкеры сохраняют как шпаргалку.

**ВИЗУАЛ.** Говорящая голова + жемчужное украшение на голове (визуальный крючок-вопрос). Врезки меняются каждые 1–2с (плотность, скучать некогда). Анимированный счётчик в углу = «просмотры в реальном времени» (иллюзия вирального). Финал: врезки исчезают, замедление = пространство, чтобы мысль «прилипла».

**МЕХАНИКА ЗАЛЁТА.** Досмотр — число держит + высокий темп + предощущение финала. Пересылка — мета-твист (момент инсайта). Сохранение — шпаргалка. Комменты — «а ещё есть…» + вопросы про счётчик.

**ЧТО БЕРЁМ В PSYCONT:**
1. **Мета-структура «список, сам являющийся одним из пунктов»**: «5 признаков тревоги», построенное так, что зритель на каждом узнаёт себя → финал «вы только что прошли мини-диагностику».
2. **Врезки-примеры** (анонимные сценки/цитаты клиентов) вместо чужих видео.
3. **Темп перечисления без комментариев** («назови и покажи, не объясняй»).
4. **Число в заголовке + скобка, снимающая барьер** («даже если не считаешь себя тревожным»).
5. **Финальный мета-разворот** («вы только что сделали X и не заметили», где X — то, что обычно избегают).

## 32 — «Родительская школа: тема урока Доверие»

**ТЕМА:** газлайтинг в детско-родительских отношениях через сатиру-перевёртыш. **ТИП:** говорящая голова, сатира («анти-инструкция»).

**ХУК.** «Уважаемые родители, рассаживаемся, тема урока доверия». Механизмы: ролевое переключение (родитель → ученик); интрига через «доверие» (ждёшь полезный контент про воспитание); тон «менторской скуки» (контраст с содержанием); «рассаживаемся» = прямое обращение, «ты в классе».

**ФОРМАТ.** Сатира-перевёртыш: «учитель» серьёзно учит, как РАЗРУШИТЬ доверие, называя это залогом доверия. Через реальные слова реальных родителей. Без пометки «сарказм» — зритель доходит сам.

**СТРУКТУРА:** 1) хук (ждёшь пользу); 2) первый переворот «нужно, чтобы он не доверял никому, особенно себе» (спотыкаешься); 3) доведение до абсурда; 4) **серия дословных диалогов** «ребёнок говорит / родитель переименовывает» («вы на меня орёте» / «кто на тебя орёт?»; «вы тупая» / «я не обзываюсь, я выстраиваю гипотезу»); 5) демонстрация на зрителе («започувствовали, сразу доверие возникло»); 6) финал-гвоздь без иронии «тогда будут тёплые доверительные отношения».

**РАЗБОР ТЕКСТА.** Нигде не говорит «так нельзя» — **сатира обходит защиту** (смех первым → узнавание → неловкость; смех снижает оборону). «Кумпол» = детская речь (фокус на отношении к мыслям ребёнка как несерьёзным). **«Я выстраиваю гипотезу»** = прямая демонстрация газлайтинга через переопределение слов. Повтор паттерна «реальность / переименование» = структура газлайтинга лучше любой лекции.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** Зритель А (был таким ребёнком) — узнавание физическое («мне это говорили») + облегчение («я не сумасшедший») + боль → пересылает в семью/психологу. Зритель Б (родитель) — смех → стоп «я так говорю» → дискомфорт → коммент (защитный или честный). **Триггеры:** дословные фразы (не обобщения) + демонстрация на зрителе (понимание → переживание).

**ВИЗУАЛ.** Говорящая голова, статичный фон, намеренно простой (усиливает «урок»). Вся работа через мимику (закатывание глаз = «учитель объясняет очевидное»). Плашка «Родительская школа: тема урока "Доверие"» весь ролик = эффект слайда, удерживает рамку сатиры.

**СЛАБОЕ МЕСТО:** нет выхода из сатиры («а что вместо?») — для воронки потеря.

**ЧТО БЕРЁМ В PSYCONT:**
1. **Сатира-перевёртыш** > прямой дидактики, когда тема задевает защиту («не газлайтьте детей» → закрытие; абсурдный урок → досматривают и узнают себя).
2. **Дословные фразы > терминов** («кто на тебя орёт?» > «обесценивание чувств»).
3. **Демонстрация паттерна на самом зрителе** (понимание → телесное переживание).
4. **«Учительская» рамка как контейнер** (защита от обвинений: «это же урок»).
5. **Минимальный монтаж не слабость** (сила в тексте + мимике).
6. **Добавить выход из сатиры в финале** для воронки («хочешь разобраться, как это было с тобой?»).

## 33 — «Блоги психологов: советы, которые НЕ работают»

**ТЕМА:** разоблачение «постить часто» + кейс с цифрами → продажа базы форматов (Dadre.ru). **ТИП:** разбор-ошибки + кейс + мягкая продажа.

**ХУК.** Визуальный: 2 плашки одновременно «Блоги психологов» (красная) + «Советы, которые НЕ РАБОТАЮТ» (белая, «НЕ» капсом). Вербальный: «Если бы клиенты не приходили ко мне в терапию с моего блога…». **Двойной удар:** «НЕ РАБОТАЮТ» = тревога «делаю не то»; «Блоги психологов» = аудиторная нарезка (идентифицирует себя); условное «если бы не…» = open loop в первые 3 секунды.

**ФОРМАТ.** Разбор-ошибки + кейс с цифрами + продажа. Говорящая голова, петличка, дома, 2 вставки скриншотов.

**СТРУКТУРА:** 1) хук + «блог работает, я знаю как» (авторитет без декларации); 2) разоблачение «не стала бы постить 3-5-10 раз» + механика (алгоритм учится на частоте, выгораешь → «ПРОСМОТРЫ УПАДУТ!» капсом = якорь) + эмпатия («дети, семьи, работа»); 3) **кейс-доказательство** (скрин Insights: 7 reels = 4000 подписчиков, 659к); 4) формат, который работает («думающая аудитория»); 5) обострение боли («свобода от сарафанного радио, агрегаторов») + «не нарушая этику»; 6) продажа (база, 27 мая, CTA «база» в комменты / ссылка).

**РАЗБОР ТЕКСТА.** Маленький масштаб (7 постов) = психологически безопасно/достижимо. **«Не нарушая этику»** = снятие главного возражения психологов перед продажей. «Классная думающая аудитория» = язык ценностей психолога, не маркетолога. Двойной CTA (слово в комменте проще ссылки) = снижение трения + разгон охвата.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** 0–3с идентификация+тревога. 3–15с **снятие вины** («не обязан постить часто» — работает лучше нового совета). 15–35с недоверие «докажи». 35–55с доверие через скрины (реальные, не нарисованные; достижимо). 55–80с картина будущего на языке психолога. «Не нарушая этику» = снятие возражения перед покупкой.

**ВИЗУАЛ.** Два слоя текста (субтитры + фирменные бордовые плашки в 3 точках: хук/середина/CTA). Мимика «скептик→доказывающий→приглашающий» управляет состоянием. Скриншоты с телефона = «пауза-доказательство». Петличка с медведем = снижение дистанции.

**МЕХАНИКА ЗАЛЁТА.** Досмотр — смена эмоц.регистра каждый блок (тревога→облегчение→«докажи»→доказательство). Пересылка коллеге «и я об этом». Сохранение — цифры-референс. Комменты — слово «база».

**ЧТО БЕРЁМ В PSYCONT:**
1. **Хук «разоблачение совета для точной аудитории»** (плашка ниши + плашка отрицания).
2. **Снятие вины как удержание** («ты не обязан делать X» > нового списка).
3. **Кейс с небольшими конкретными цифрами** (7 постов / 4000 — достижимо > 100к).
4. **Скриншот с реального экрана** как доказательство (документальность).
5. **«Не нарушая этику»** — обязательная оговорка при продаже психологам.
6. **Двойной CTA** (ссылка + слово в комменте).
7. **Апелляция к качеству аудитории**, не количеству (язык ценностей психолога).

## 34 — «Запрос клиента / спустя полгода терапии» (бабушка)

**ТЕМА:** результат терапии — не идеальный человек, а принятие своей «сумасшедшинки» при владении собой. **ТИП:** мем-перебивка (вирусная вставка чужого видео).

**ХУК.** Кадр 1: психолог + текст «Запрос клиента: "Хочу перестать тревожиться, не косячить, быть всегда собранной, уверенной и спокойной"». **Дословный запрос 80% аудитории**, разговорным языком («не косячить»), без вступления → мгновенное узнавание «это про меня».

**СТРУКТУРА.** Сетап (кадр 1, психолог, нейтрально, не комментирует) → **слом** (кадр 2: бабушка в платке за прилавком хозтоваров + «Спустя полгода терапии:» + «я просто немножко сумасшедшая») → развёртка фразы по 5 кускам («и даже не немножко очень» → «но тем не менее» → «значит я владею собой» → «а голова у меня хорошая»).

**РАЗБОР.** **Резка одной фразы на 5 кадров** = удержание (синтаксически не завершена → нельзя бросить), каждый кусок смешнее и глубже. Контраст молодой психолог / народная бабушка = «инсайт из самого неожиданного источника». Надпись «Спустя полгода терапии» связывает два мира (без неё — просто смешной ролик). Бабушка говорит живой неотредактированной речью = достоверность.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** 0–3с узнавание + лёгкий стыд (за идеалистичный запрос «быть другим человеком»). 3–5с шок+смех (слом ожидания экспертного ответа). 5с+ «бабушка говорит точную вещь» — инсайт в комедии (принятие себя важнее исправления). Финал «а голова у меня хорошая» = достоинство, тёплое послевкусие.

**МЕХАНИКА ЗАЛЁТА.** Досмотр — резаная фраза. Пересылка «это про нас/терапию» (личная, не репост в сторис). Виральность на пересечении двух аудиторий (в терапии + смеющиеся над бабушкой).

**ЧТО БЕРЁМ В PSYCONT:**
1. **Формат «запрос клиента → неожиданный ответ»** (показать, не объяснять — зритель сам приходит к выводу).
2. **Мем-перебивка** (вирусный чужой момент + надпись-контекст «когда клиент говорит что…» = готовый reels).
3. **Идея «принятие себя вместо исправления»** через юмор (не сформулирована прямо → зритель дошёл сам).
4. **Надпись-контекст** превращает чужой контент в проф.высказывание (минимальная редакция).
5. **Молчаливый сетап** (психолог ничего не говорит — для тех, кому некомфортно в камеру).

## 35 — «Твоя бесплатная терапия начнётся через 2…» (5 вопросов о страхе проявляться)

**ТЕМА:** техника самокоучинга — 5 вопросов о страхе публичности. **ТИП:** говорящая голова + текст поверх + реквизит-якорь (банка SMELOST).

**ХУК (два блока).** Вверху «твоя бесплатная терапия начнется через… 2», внизу цитата в кавычках «"я хочу проявляться, но боюсь"». «Бесплатная терапия» = ценность без обязательства, «терапия» легитимизирует. **Обратный отсчёт = эффект Зейгарник** (мозг не терпит незавершённого паттерна, досматривает до нуля). **Цитата в кавычках = зеркало, не диагноз** («автор называет мою мысль» → нет сопротивления). Рациональный + эмоциональный уровень одновременно.

**ФОРМАТ.** Техника пошагово + реквизит как нарратив. Банка SMELOST («смелость» латиницей) с первого кадра, открывают и пьют в финале = сюжетная дуга. Нумерация X/5 вверху (удержание + структура + снижение когнитивной нагрузки).

**СТРУКТУРА:** хук → вопрос 1 «каким боюсь показаться? перед кем конкретно?» (заземление); вопрос 2 «кого может ранить мой успех?» (самый нетривиальный — переворот логики: страх как защита другого); вопрос 3 «что поможет идти ВМЕСТЕ со страхом» (ACT-логика: страх не враг); вопрос 4 «если не получится — на что опереться?» (антикатастрофизация); вопрос 5 «зачем мне важно проявляться?» (ценностный якорь) → «сохраняй и читай описание» + пьёт из банки.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** ЦА: хочет вести блог, застрял «боюсь и не знаю почему». Цитата = «меня видят» (снимает защиту). Вопросы → **отвечает в голове = интерактивное упражнение** (удерживает лучше монтажа, нельзя перемотать без потери смысла). Вопрос 2 = интеллектуальное удивление. Нумерация = прогресс-бар (трудно бросить на 60%). Финал-банка = выдох + символизм.

**ВИЗУАЛ.** Приземлённая эстетика (кухня, гирлянда, тёплый свет) = «живой специалист, не инфобизнес». **Спокойное лицо без улыбки/жестов** = прямой разговор один на один (не конкурирует с текстом). Нумерация X/5 = навигация. Банка (красный на тёмном) = единственный акцент, держит взгляд, пока читается текст; финал (открыть+выпить) = смысловая точка.

**МЕХАНИКА ЗАЛЁТА.** Досмотр — отсчёт + нумерация + интерактив. **Сохранение — главная механика** (5 вопросов не запомнить с первого раза, требуют письменных ответов; «сохраняй» = логичное следствие формата). Пересылка умеренная (нишевая). Комменты — вопрос 2.

**ЧТО БЕРЁМ В PSYCONT:**
1. **Хук «твоя бесплатная терапия / цитата-зеркало в кавычках»** (кавычки обязательны = называет мысль, не диагноз).
2. **Нумерация X/N как механика удержания** (навигация, не декор).
3. **Вопросы вместо советов** (честнее, меньше сопротивления + демонстрирует метод).
4. **Реквизит с символизмом** (SMELOST — нарративная дуга без слов; финальное действие = точка).
5. **«Спокойное лицо» как стиль** (продаёт содержанием, образ «специалиста» не «блогера»).
6. **CTA, совпадающий с уже сформированным намерением** («сохраняй» озвучивает то, что зритель уже хочет).
