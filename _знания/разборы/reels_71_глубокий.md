# Глубокий разбор reels 71 (маркетолог + психолог + редактор)

---

## 71 — «Я психолог, и мне нужно набрать четырёх человек» (продажа через личный кейс)

**ТЕМА:** психолог Лера продаёт набор в терапию через личную историю о синдроме самозванца (расщепление «снаружи я молодец / внутри ничтожество»), показывая результат терапии на себе. **ТИП:** говорящая голова с субтитрами, один дубль.

**ХУК.** «Я психолог, и мне в работу нужно набрать четырёх человек для полного счастья. И я не знаю, как продавать вам идею психотерапии». Три механики: **признание беспомощности вместо продажи** (ждёшь «вот мои услуги» — получаешь разоружение = аномалия, стоп-скролл); «четыре человека для полного счастья» = самоирония, характер (не «набираю клиентов»); интрига «расскажу про себя как про самый главный кейс в своей жизни» (обещание истории, не лекции).

**ФОРМАТ.** Признание/исповедь от первого лица как кейс (личная история + продающий аргумент). **Этическое ограничение (нельзя отзывы клиентов) превращено в нарративное преимущество** — прямо называет причину, почему рассказывает о себе.

**СТРУКТУРА:** 1) заявка (психолог, ищу четырёх; продавать терапию сложно + запрет на отзывы → расскажу про себя); 2) **состояние ДО** (снаружи: никчёмная, друзья из жалости / внутри: «я самая крутая, чуть напрягусь — будет гениально» = расщепление нарциссического стыда); 3) последствие (изоляция, страх показать «уродливую» часть); 4) **состояние ПОСЛЕ** («место посмотреть на свою уёбищность и не отказаться от себя; друзья видели всё и всё равно любят; я не обязана быть гениальной — я просто Питер Паркер»); 5) призыв «такие цыганские фокусы, приглашаю вас» (тихий итог без давления).

**РАЗБОР ТЕКСТА.** Низкая живая лексика («уёбищность», «цыганские фокусы») = а) разрушает дистанцию «холодного специалиста»; б) «из той же среды»; в) запоминается; г) снижает тревогу перед «серьёзной психологией». **Метафора «Питер Паркер»** (обычный парень, не супергерой) = обезоруживающе, поп-культурно, запоминается. «Знания — микрон в масштабе солнечной системы» = точно про синдром самозванца. **«Отзывы клиентов брать не могу, это неэтично»** = один из сильнейших продающих ударов (сигнал этики в нише коучей со скриншотами переписок), вставлен органично в историю.

**ВИЗУАЛ.** Одна статичная домашняя локация (стол у окна, фикус, книги, гирлянда, уютный кардиган) = «живой человек у себя дома», не студия. Розовые жирные субтитры (теплота, неформально, немедицински; без звука читается). Активная жестикуляция + эмоциональная дуга мимики (ирония → напряжение/прищур → мягкая улыбка/расслабление в финале). **Без склеек = усиливает исповедь.** Нет хук-плашки — цепляет первая фраза речи.

**ПСИХОЛОГИЯ ЗРИТЕЛЯ.** 3с «сейчас реклама» → «не знаю как продавать» = аномалия. «Расскажу про себя как кейс» = **смена режима с «смотрю рекламу» на «слушаю историю»** (истории не фильтруются рекламным иммунитетом). Расщепление «снаружи никчёмный / внутри тайно грандиозный» = широкое попадание (тревожная привязанность, самозванец, перфекционизм); **автор говорит это про себя → снимается защита**. Стыд = сильная эмоция, держит до конца. Финал «выдохнуть захотелось» + телесное расслабление = эмоциональный якорь (зритель хочет этого состояния).

**МЕХАНИКА ЗАЛЁТА.** Досмотр — незакрытая дуга (расщепление описано, чем кончилось — непонятно до середины) + эмоциональная дуга + неожиданные формулировки. **Пересылка высокая** («это ты / про меня» — узнаваемый паттерн, про который не говорят вслух). Комменты — «это я», «как записаться» (прямая воронка). Сохранение умеренное.

**ПОЧЕМУ ЗАЛЕТЕЛО:** редкий формат продажи без продажи (контраст с «полезняк/кейсы/реклама»); точное попадание в болевой паттерн (расщепление, которое мало кто называет вслух); полное доверие через стиль (живая речь, оговорки, один дубль, домашний фон → «она такая же как я»).

**ЧТО БЕРЁМ В PSYCONT:**
1. **Формула «не знаю, как вас продавать — расскажу про себя»** = продающий рилс без ощущения продажи.
2. **«До/после» через личный кейс ТЕРАПЕВТА, не клиента** (обходит этику отзывов + снижает дистанцию; называние ограничения вслух = плюс к доверию).
3. **Расщепление «снаружи никчёмный / внутри тайно грандиозный»** как точка входа в тему стыда (готовая тема).
4. **Финальный перформативный жест** (результат не декларируется, а показывается телесно — «выдохнуть захотелось» + расслабление).
5. **Степень формальности языка должна совпадать с автором и аудиторией** (мат — наблюдение, не правило).
