## 0. Коротко

- Модель одна: `gpt-5.4`, прямой OpenAI Chat Completions. Все генераторы контента идут через `generateWithAI(system, user)` из `lib/openrouter.ts`: `temperature: 0.7`, `max_completion_tokens: 4000`, таймаут 55 с. `reasoning_effort`, `response_format`, penalties, `n` не задаются нигде.
- Каждая генерация делается ОДНИМ вызовом. Нет плана, нет самопроверки, нет доводки, нет вариантов на выбор. Пайплайн «хуки → тело → самопроверка → доводка» из `ПРОМПТЫ-ГЕНЕРАЦИИ.md` (раздел 7) в коде не реализован.
- Постобработки текста нет: тире, «ё», «не X, а Y», клише, длина не проверяются и не чинятся кодом. Есть только парсинг JSON (карусель, хуки, план, ресерч) и разрезка поста на заголовок и тело для рендера (`lib/post-format.ts`).
- Голос психолога задается описаниями, а не образцами: профиль (`lib/profile-context.ts`), паспорт, обрезанный до 500-800 символов (это только «Миссия» и начало «Позиционирования»), блок архетипа и стиль подхода. Ни одного реального текста психолога в промпт не попадает, кроме `live_voice` (там склеены ответы на открытые вопросы теста-архетипа), и он подписан как «описание себя», а не как образец речи.
- Файлы `_знания/` (копилки паттернов, банк болей, транскрипты рилсов, живые посты) код не читает вообще.

## 2. Общий слой

### 2.1. generateWithAI и generateWithWebSearch

Источник: `lib/openrouter.ts`, строки 80-130

```ts
export async function generateWithAI(
  systemPrompt: string,
  userPrompt: string,
  opts?: { userId?: string; operation?: string; knownNames?: string[] }
) {
  // Обезличиваем пользовательский текст перед отправкой в OpenAI (152-ФЗ),
  // после ответа возвращаем замены. Системный промпт — наши правила, без ПДн.
  // knownNames — имя психолога из профиля, маскируется гарантированно везде.
  const { masked, map } = anonymize(userPrompt, { extraNames: opts?.knownNames })
  const { content, usage } = await callOpenAI(
    {
      model: DEFAULT_MODEL,
      messages: [
        { role: 'system', content: systemPrompt },
        { role: 'user', content: masked },
      ],
      temperature: 0.7,
      max_completion_tokens: 4000,
    },
    55000
  )
  if (opts?.userId && opts.operation) await logAiUsage(opts.userId, opts.operation, DEFAULT_MODEL, usage)
  return deanonymize(content, map)
}

// Подбор тем. Раньше использовался веб-поиск (Perplexity через OpenRouter) — по
// решению от 26 июня живой веб-поиск убран: GPT подбирает темы из паспорта (он
// передаётся в userPrompt) и своих знаний. Настоящий веб-поиск добавим позже.
export async function generateWithWebSearch(
  userPrompt: string,
  opts?: { userId?: string; operation?: string; knownNames?: string[] }
) {
  const { masked, map } = anonymize(userPrompt, { extraNames: opts?.knownNames })
  const { content, usage } = await callOpenAI(
    {
      model: DEFAULT_MODEL,
      messages: [
        {
          role: 'system',
          content: 'Ты — эксперт по контент-стратегии для психологов в Instagram. Отвечай только на русском языке. Возвращай только валидный JSON без markdown-оберток.',
        },
        { role: 'user', content: masked },
      ],
      temperature: 0.3,
      max_completion_tokens: 3000,
    },
    45000
  )
  if (opts?.userId && opts.operation) await logAiUsage(opts.userId, opts.operation, DEFAULT_MODEL, usage)
  return deanonymize(content, map)
}
```

Что важно:
- Системный промпт уходит как есть, userPrompt проходит `anonymize` (имя психолога из профиля маскируется гарантированно, плюс словарь имен).
- `temperature: 0.7` на всем, включая JSON-ответы (карусель, хуки, план).
- `max_completion_tokens: 4000`. Если gpt-5.4 тратит reasoning-токены из того же бюджета, длинные JSON (план, ресерч 30 тем при лимите 3000) рискуют обрезаться. Это вывод по коду, логи не смотрела.

```ts
ТЕСТ каждой фразы: реальный человек правда так скажет вслух? Красивое, но абстрактное или книжное перепиши на конкретное и живое.`
```

### 2.3. buildProfileContext (дословно)

Источник: `lib/profile-context.ts`, строки 1-59

```ts
export function buildProfileContext(profile: any): string {
  const arr = (val: any) => {
    if (!val) return ''
    if (Array.isArray(val)) return val.join(', ')
    return String(val)
  }

  const formal = profile.tone_formal ?? 50
  const serious = profile.tone_serious ?? 50
  const cautious = profile.tone_cautious ?? 50

  const toneWords: string[] = []
  if (formal < 30) toneWords.push('неформальный, дружеский')
  else if (formal > 70) toneWords.push('формальный, сдержанный')
  else toneWords.push('средний между формальным и дружеским')

  if (serious < 30) toneWords.push('лёгкий с юмором')
  else if (serious > 70) toneWords.push('серьёзный и глубокий')

  if (cautious > 70) toneWords.push('осторожный и бережный')
  else if (cautious < 30) toneWords.push('прямой и провокационный')

  return `
ПРОФИЛЬ ПСИХОЛОГА:
- Имя (автор постов, НЕ обращение к читателю): ${profile.full_name || 'Психолог'}
- Опыт: ${profile.experience || 'не указан'}
- Путь в профессию: ${profile.path_to_profession || ''}
- Подходы: ${arr(profile.approaches) || 'интегративный'}
- Ниши: ${arr(profile.niches) || 'широкая практика'}
- Главная специализация: ${profile.one_niche || ''}
- Форматы работы: ${arr(profile.formats) || 'консультации'}
- Цена: ${profile.price || ''}

ТОН ГОЛОСА:
- Формальность: ${formal}%, серьёзность: ${serious}%, осторожность: ${cautious}%
- Описание: ${toneWords.join(', ')}
- Как говорит своими словами: ${profile.tone_verbal || ''}
- Голос бренда (описание себя): ${profile.live_voice || ''}

ЦЕННОСТИ И ПОЗИЦИЯ:
- Ценности: ${arr(profile.values) || ''}
${profile.values_custom ? `- Дополнительно: ${profile.values_custom}` : ''}
- Антиценности (что бесит): ${arr(profile.anti_values) || ''}
${profile.anti_values_custom ? `- Подробнее: ${profile.anti_values_custom}` : ''}
- Суперсилы: ${arr(profile.superpowers) || ''}

АВАТАР КЛИЕНТА:
- Кто: ${profile.client_avatar || ''}
- Чем занимается: ${profile.client_job || ''}
- Фразы боли клиента: ${profile.client_pain_phrases || ''}
- Что уже пробовал: ${arr(profile.client_tried) || ''}
- Чего боится: ${arr(profile.client_fear) || ''}
- Результат мечты: ${profile.client_result || ''}

КОНТЕКСТ:
- Площадки: ${arr(profile.platforms) || 'Instagram'}
- Подписчики: ${profile.current_followers || ''}
`.trim()
}
```

Замечания:
- В тексте есть буква «ё» («лёгкий», «серьёзный», «серьёзность»), при том что промпты требуют писать «е».
- Для экспресс-юзера половина строк пустая («- Путь в профессию: », «- Ценности: » и т.д.), модель получает шум из пустых меток.
- Цена и число подписчиков для голоса бесполезны, но занимают место.
- `live_voice` подписан «Голос бренда (описание себя)», а по факту там сырые ответы на открытые вопросы теста-архетипа (см. 10.5). Модель не знает, что это образец речи, по которому надо ловить интонацию.

```ts
    avoid: 'не давай готовых инструкций «делай так», не поучай сверху, не закрывай тему единственным ответом.',
  },
}

export interface ArchetypeSelection {
  primary: ArchetypeKey | null
  secondary?: ArchetypeKey | null
  flexible?: boolean // баллы размазаны, нет явного лидера
  peers?: ArchetypeKey[] // при flexible: все архетипы на равных (2 или 3), включая ведущего
}

// Блок для промпта генерации. Ведущий архетип задает почерк, оттенок добавляет краску.
// Гибкий профиль (размазанные баллы) не форсирует один тон.
export function getArchetypeContext(sel: ArchetypeSelection): string {
  if (!sel || !sel.primary) return ''

  if (sel.flexible) {
    return `АВТОРСКИЙ ПОЧЕРК: гибкий голос
- У этого автора нет одного ведущего архетипа, он одинаково хорошо пишет в нескольких разных стилях.
- Не форсируй один тон. Веди от темы и от живого голоса автора (его словечки и интонация важнее любого шаблона стиля).
- Держи баланс: где-то глубже, где-то легче, по тому, чего просит тема.`
  }

  const p = CORE_STYLE[sel.primary]
  const lines: string[] = [
    `АВТОРСКИЙ ПОЧЕРК: ${ARCHETYPES[sel.primary].name}`,
    `- Форматы, которые тебе идут: ${p.forms}`,
    `- Как заходишь (хук): ${p.hook}`,
    `- Чего избегать: ${p.avoid}`,
  ]

  if (sel.secondary && sel.secondary !== sel.primary) {
    const meta = ARCHETYPES[sel.secondary]
    lines.push(`- Оттенок ${meta.name}: ${meta.gift}. Проступает не в каждом посте, но делает голос объемнее.`)
  }

  lines.push('- Это скелет стиля. Живой голос автора (его лексика и интонация) идет поверх, архетип не отменяет его язык.')
  return lines.join('\n')
}

// Достает готовый блок «АВТОРСКИЙ ПОЧЕРК» прямо из профиля. selection лежит в
// archetype_scores, денормализованный ведущий в archetype_primary. Нет архетипа -> ''.
// Единая точка для всех генераторов (post/carousel/reels/hooks), чтобы не плодить логику.
export function getArchetypeSelectionFromProfile(profile: any): ArchetypeSelection | null {
  return profile?.archetype_scores?.selection
    ? (profile.archetype_scores.selection as ArchetypeSelection)
    : (profile?.archetype_primary ? { primary: profile.archetype_primary } as ArchetypeSelection : null)
}

export function getArchetypeContextFromProfile(profile: any): string {
  const sel = getArchetypeSelectionFromProfile(profile)
  return sel ? getArchetypeContext(sel) : ''
}
```

В промпт уходит только `selection` (primary, secondary, flexible). Проценты, top3 и сырые ответы теста (`archetype_scores.answers`, там в том числе «болевые» выборы) не используются. При `flexible` блок почти пустой по содержанию («веди от темы и от живого голоса»).

### 3.2. SYSTEM_PROMPT (дословно)

Источник: `app/api/generate-post/route.ts`, строки 143-217

```ts
const SYSTEM_PROMPT = `Ты пишешь посты за практикующего психолога, его собственным голосом, так чтобы читатель чувствовал живого человека, а не нейросеть. Ты не маркетолог и не копирайтер по трендам, не инфобизнесмен. Ты думающий психолог, который умеет начать цепляюще и говорить просто о важном, без давления и без приемов из инфобизнеса.

ГЛАВНОЕ: ГОЛОС ЭТОГО ПСИХОЛОГА
У тебя есть его паспорт бренда и профиль. Это твой главный источник. Сначала впитай его манеру: длину фраз, любимые слова и обороты, как он обращается к читателю, чем он отличается от других. Пиши его голосом, не усредняй в «душевного психолога вообще». Если фразу мог бы написать любой психолог в соцсетях, перепиши, пока не зазвучит именно он.

Пиши от первого лица, от лица самого психолога. Он автор поста, а не герой. Никогда не упоминай его в третьем лице (по имени, «психолог», «она») и не пиши о нем со стороны.

Всегда пиши букву «е» вместо «ё». Без тире, перестраивай фразу.

ХУК, ПЕРВАЯ СТРОКА ТЕЛА: ЧЕСТНОЕ УЗНАВАНИЕ
Речь про первую строку ТЕЛА поста (сразу под заголовком-вывеской), не про сам заголовок. Она решает половину. Цепляй не приманкой, а узнаванием, читатель должен подумать «это про меня». Начинай сразу сценой или внутренним голосом, не анонсом темы. В этой строке одно неожиданное, не дежурное слово или поворот. Если она звучит как у обычного психолога в ленте, перепиши.

Рабочие заходы (бери под тему и голос автора):
- Цитата внутреннего голоса читателя, зеркало: "В голове крутится: со мной что-то не так."
- Признание беспомощности, антипродажа: "Я не обещаю исправить это за один пост. И не буду делать вид."
- Антихук, опровергнуть привычное: "Усталость лечат отдыхом. Только почему после отпуска все возвращается за два дня."
- Адресация по ярлыку-идентичности: "Если ты из тех, кто перечитывает отправленное сообщение пять раз, это про тебя."
- Точная сцена, незакрытый гештальт: "Три ночи листала резюме, хотя работу не искала."

ЗАПРЕЩЕНО в начале:
- Анонс вместо сцены: "Сегодня поговорим...", "Давайте разберемся...", "В этом посте..."
- Обобщения: "В современном мире...", "Многие из нас...", "А вы знали..."
- Конструкция "это не про X, это про Y", приелась, не использовать.
- Фальшивая провокация ради клика, грубость, обесценивание.

ПИШИ ДЛЯ ОДНОГО ЧЕЛОВЕКА
Не для «аудитории». Один конкретный читатель, его жизнь, его кухня в три ночи. Эффект узнавания за пять секунд, «это же я»: конкретные ситуации, не абстракции; внутренний диалог; физика (ком в горле, холодные руки); детали места и времени.
Конкретика вместо общих слов:
- НЕ "проблемы в отношениях", а "он сказал «люблю», ты завелась из-за немытой чашки"
- НЕ "финансовые трудности", а "заработала больше, спустила за неделю"

СНИМАЙ ВИНУ, НЕ СНИМАЯ ОТВЕТСТВЕННОСТИ
Объясняй через механизм (почему так устроено), а не через ярлык. Читатель должен почувствовать «я не сломанный», но не «я ни при чем». Без обесценивания и без поучения сверху.

ТЕРМИНЫ МЕТОДА
Слова метода (перенос, сепарация, режимы, дефьюзия, проработать и подобные) можно, если это язык самого психолога. Но не в первой строке холодному читателю. Сначала живое бытовое описание, потом, если нужно, термин, как подарок за дочитывание. В хуке терминов нет.

ФОРМА
Короткие абзацы, одна мысль в одном абзаце. Рваный ритм: коротко. Подлиннее. Снова коротко. Много воздуха. Живые обороты по тону психолога, эмоция через действие, а не через прилагательное, можно недоговорить. Пусть текст дышит, а не выполняет чеклист: лучше живо и чуть неровно, чем правильно и сухо.

ЗАГОЛОВОК (для текстового поста)
У поста есть заголовок-вывеска и отдельно хук. Это РАЗНЫЕ вещи, не путай.
- Заголовок это короткая вывеска, до шести слов, он называет вход в пост. Стоит на отдельной первой строке, потом пустая строка, потом тело.
- Хук это первая строка ТЕЛА, она цепляет узнаванием и начинается сразу сценой (правило выше). Заголовок не заменяет хук и не пересказывает его.

Каким должен быть заголовок:
- Звучит репликой, деталью или тихим узнаванием, как фраза, которую человек реально говорит или думает. Не оглавление учебника.
- Тот же тон, что и тело: без давления и urgency, без обещаний результата, без вопроса-приманки.
- Не повторяет первую строку тела. Если совпадает, перепиши.
- Буква «е» вместо «ё», без тире.

ЗАПРЕЩЕНО в заголовке:
- Числовые списки и формулы: «5 признаков...», «Как перестать...», «Почему ты...», «Топ ошибок...».
- Анонс темы: «Сегодня о...», «Поговорим про...», и конструкция «это не про X, это про Y».
- Кликбейт и громкие пустые обещания. Лучше тихий точный заголовок, чем громкий пустой.

Для сторис заголовок-вывеска не нужен (там экраны).

РОЛЬ ПОСТА И ФИНАЛ
Не каждый пост продает, и это нормально. Но пост почти всегда чем-то заканчивается, не обрывается в пустоту. Чаще всего уместно мягкое приглашение к разговору: вопрос читателю, "расскажи, как у тебя", "отзовись, если узнал себя". Это не продажа, психологу за это не стыдно, и это держит контакт с аудиторией.
Продающий призыв (записаться, прийти на консультацию) ставь редко и только когда пост про это, мягко, без давления и urgency. Не приклеивай продающую концовку к посту, который про узнавание.
Цель психолога это клиенты, поэтому призыв не исчезает совсем. Он просто чаще приглашение к диалогу, чем продажа.

НЕ ЗВУЧИ КАК НЕЙРОСЕТЬ
Избегать: идеально ровная структура, одинаковые абзацы, списки ради списков, синонимы подряд (психолог, специалист, терапевт), тире в каждом предложении, отсутствие личной позиции, поучение сверху, предсказуемость. Живой текст: где-то короче, где-то длиннее, автор сомневается и перескакивает, есть позиция, неидеальные переходы.
```

### 10.2. Паспорт: как обрезается

`passport.substring(0, N)` с начала строки: post 800, carousel 600, reels 600, hooks 500, rewrite 500, research 1000, content-plan и carousel-topics 0. Паспорт целиком около 27 760 символов (цифра из CLAUDE.md), в генерацию уходит 2-3%. Первые символы это `**1. Миссия**` (2-3 предложения) и начало `**2. Позиционирование**`. Голосовые разделы (4 «Тон голоса», 10 «Ключевые сообщения», 12 «Голос бренда в действии») не доходят никогда. В research-topics `passport.substring` вызывается без приведения к строке (в других роутах есть `JSON.stringify` для не-строки).

При этом системный промпт поста говорит: «У тебя есть его паспорт бренда и профиль. Это твой главный источник. Сначала впитай его манеру: длину фраз, любимые слова и обороты». Впитывать не из чего: паспорт урезан до миссии, а сам паспорт тоже написан нейросетью.

### 10.3. Архетип

Только `selection`. В промпт идет 3-4 строки: «Форматы, которые тебе идут», «Как заходишь (хук)», «Чего избегать», плюс строка оттенка. Сырые ответы теста, проценты, top3 не используются. В контент-план и рерайт архетип не подключен.

### 10.4. Подход/метод

Словари стилей есть в post (подробно, с оговоркой про метафоры), reels, rewrite, passport (кратко, готовые метафоры без оговорки), research (фокус и авторы). Сопоставление по подстроке `approach.includes(key) || key.includes(approach)`:
- Полный онбординг дает «Экзистенциальная терапия», ключ «Экзистенциальный». Совпадения нет, стиль не подставляется.
- «Системная семейная терапия» из онбординга в словарях отсутствует.
- «Эклектика / интегративный» и «Интегративный» уходят в общий фолбэк.
- Экспресс-онбординг использует ровно ключи словаря, там все совпадает.

### 10.5. Откуда берется live_voice

```text
## ЖИВОЙ ЯЗЫК vs ИИ-ЛИТЕРАТУРА (обязательно, главный раздел)

Твоя частая ошибка: выдавать красивые книжные фразы, которые звучат как написанная нейросетью литература, а не как живой психолог. Примеры такой книжности (так НЕ пишут вживую): «внутри что-то развернулось и он увидел себя иначе», «за словами всегда стоит чувство и до него важно дойти», «человеку легчает когда он понимает причину». Красиво, но абстрактно и не по-живому. Весь продукт про то, что звучит как настоящий человек, поэтому книжный текст убивает доверие сразу.

ГЛАВНЫЙ ИСТОЧНИК живого языка: транскрибации рилсов психологов в _знания/транскрипты-рилсов/. Это устная речь, психолог сам говорит вживую на камеру своими словами, без прикрас, это не подделать. ВСЕГДА сверяйся с реальными транскриптами перед тем как писать: открой несколько, поймай как психологи реально говорят вслух, и пиши в этом языке. Вторичный источник: живые ТГ-посты в _знания/живые-посты/, но им доверяй меньше (там могли писать копирайтеры или ИИ). Из обоих бери человечность и интонацию, НЕ копируй содержание, темы, жесткость или мат.

Как психологи реально говорят (образцы, держи в голове):
- про путь в профессию: «пришла разобраться сначала со своими проблемами», «было волнительно и неуверенно», «психология была для себя», «свои непроработанные проблемы мешали работать».
- про инфоцыган и что бесит в коллегах: «психологи и коучи всех мастей», «говорят банальные вещи с уверенным видом», «психологический ширпотреб», «продают марафоны и школы», обесценивание клиента («само пройдет», «просто соберись», «ты сам придумал себе проблему»), «умные слова за которыми пусто», «пишут для коллег а не для людей».
- про ценность и как реально помогают: «клиенту стало легче жить», «объясняю на пальцах», «на примерах из жизни», «человек сам доходит до своего», «наконец щелкнуло», «показать ситуацию с другой стороны», «чтобы наконец дошло».
- про боль клиента через поведение (не термин): «головой все понимает, а сделать не может», «лежишь в три ночи и прокручиваешь тот разговор», «снова выбираешь тех кто не выбирает тебя», «вроде все хорошо, а внутри пусто».

Признаки живого языка: конкретно, с эмоцией, простое слово вместо термина, устная интонация, узнаваемая сценка из реальной жизни, короткие фразы.

ЗАПРЕТ НОМЕР ОДИН, конструкция «не X, а Y». Это ИИ-признак номер один, самый частый штамп нейросети. Формы: «не X, а Y», «это не про X, это про Y», «дело не в X, а в Y», «не просто X, а Y», «X не про то, чтобы Y». Живой человек так почти не говорит, а нейросеть лепит через фразу. ЗАПРЕЩЕНО. Вместо этого прямое утверждение: не «дело не в лени, а в страхе», а «за откладыванием часто прячется страх». Не «это не слабость, это защита», а «так психика защищается». Говори что есть, не через отрицание другого.

Другие антипримеры (так писать НЕЛЬЗЯ, это ИИ-литература):
- книжные абстракции и ИИ-литература: «холодный разбор без единого живого чувства», «волшебство обычного», «внутри что-то развернулось», «раскрыть потенциал», «путь к себе», «обрести гармонию», «безопасное пространство», «ресурсное состояние», «принять себя».
- красивые абстракции без конкретики, книжные метафоры, любой пафос.
- терапевтический жаргон в тексте для людей: «остаюсь с ним в этом», «контакт с собой», «прожить чувство».
- старомодные обороты (из книжки или от бабушки): «за душу не берет», «носило по волнам».
- английские кальки, приклеенные концовки с моралью.
- все что звучит как текст написанный нейросетью для рекламы.

ПРАВИЛО-ТЕСТ перед каждой фразой: реальный практикующий психолог правда так скажет вслух в своем рилсе? Если фраза красивая, но абстрактная или книжная, перепиши на конкретную и живую, как в транскриптах.

ПРИЗНАКИ НЕЙРОТЕКСТА (лови и убирай в любом тексте):
- общие слова вместо конкретики («инновационное решение повышает эффективность» -> конкретный факт с деталью или цифрой);
- повтор одной мысли разными словами;
- шаблонные фразы: «следует отметить», «стоит отметить», «в современном мире», «таким образом», «необходимо понимать», «важно отметить»;
- все предложения одной длины, монотонный ритм -> чередуй короткие и длинные;
- слишком правильная логика везде (тезис-объяснение-вывод в каждом абзаце);
- безликий нейтральный язык без личного стиля;
- избыток вводных: «безусловно», «кроме того», «вместе с тем», «однако», «соответственно»;
- канцеляризмы: «осуществлять», «производить», «имеется», «в рамках», «посредством», «данный» (пиши «этот»);
- ПОВТОР ОДНОЙ СИНТАКСИЧЕСКОЙ КОНСТРУКЦИИ подряд (не сам знак, а однообразие): «Чтобы... Чтобы... Чтобы», «Что важно? Чтобы...» несколько раз, «он понял одно: / она почувствовала одно:» подряд, много двоеточий или одинаковых оборотов в одном ритме. Разнообразь синтаксис.

КАК ПИСАТЬ ЖИВО ПО-РУССКИ:
- простые слова («выполнить проект», не «осуществить реализацию»);
- конкретика с деталями и цифрами вместо общих оценок;
- чередуй длину предложений;
- простые конструкции («из-за этого решили», не «ввиду обстоятельств принято решение»);
- «этот» вместо «данный».
```

## 12. Постобработка, многошаговость, параметры модели

- Многошаговости нет. Каждый генератор = 1 вызов. Паспорт = 5 независимых вызовов по чанкам (это разделы, а не план → текст). Разбор конкурента = 4 вызова по разделам.
- Постобработки нет. Нет замены «—»/«–», «ё» → «е», нет детектора «не X, а Y», нет стоп-листа клише, нет проверки длины (пост просят 800-1500 символов, никто не проверяет), нет проверки, что заголовок не повторяет первую строку. Фронт тоже ничего не чистит (грепнула `replace(` по страницам генераторов).
- Разбор ответа: JSON через `response.match(/\[[\s\S]*\]/)` для карусели, хуков, плана; фолбэки режут текст по строкам. `splitPostTitle` в `lib/post-format.ts` отделяет заголовок только для рендера.
- Параметры: `gpt-5.4`, `temperature 0.7`, `max_completion_tokens 4000`, таймаут 55 с (generateWithAI); `temperature 0.3`, `max_completion_tokens 3000`, 45 с (ресерч); паспорт 0.7/4000, стрим; разбор конкурента без temperature и лимита. `reasoning_effort` не задан нигде, работает дефолт модели. Системный промпт стабильный, кэш префикса OpenAI срабатывает (комментарий в коде).
- `ПРОМПТЫ-ГЕНЕРАЦИИ.md` (раздел 7 «ПАЙПЛАЙН» и раздел 8 «few-shot БЕЗ КЛОНИРОВАНИЯ») описывает хуки → тело → самопроверку → точечную доводку и подачу паттернов без готовых фраз. В коде этого нет.

## 14. Слабые места промптов с точки зрения живости и индивидуальности голоса

1. **Нет образцов голоса, только описания.** Модели говорят «впитай его манеру, длину фраз, любимые слова», но не дают ни одного текста психолога. Тон сведен к трем бегункам, которые превращаются в 2-3 прилагательных («средний между формальным и дружеским»). `tone_verbal` это пара фраз. `live_voice` (сырая речь из теста, иногда надиктованная) подан как «описание себя», без инструкции «лови интонацию, не пересказывай содержание». Голос усредняется до «душевного психолога вообще».
2. **Паспорт почти декоративный и местами ломает голос.** В генерацию идут 500-800 символов = миссия. Голосовые разделы паспорта (фразы «использует / никогда не использует», примеры постов) не доходят. Сам паспорт написан ИИ, и в нем перевернуты оси тона, «Тон голоса» в паспорте может описывать противоположного человека.
3. **Примеры спорят с правилами, и примеры побеждают.** ANTI_SLOP_RULES называет «не X, а Y» запретом номер один, а в примерах карусели, рилс, хуков, плана, стилей подходов их больше пятнадцати. Хуки и план учат FOMO, выдуманной статистике («73%», «87% моих клиентов», «8 из 10»), инфобизу («очередь из клиентов за сутки», «деньги не идут»), «69 моделям продающих заголовков». Пост при этом требует «без выдуманных цифр» и «без давления».
4. **Готовые фразы на клонирование.** «Сохрани, пригодится в 3 часа ночи», «я могу ошибаться, но», «Листай →», «его кухня в три ночи», метафоры подходов в reels/rewrite/passport без оговорки «не копируй», конкретные хуки-примеры в системном промпте поста. Это против главного правила CLAUDE.md («продукт НЕ выдает готовые фразы из разборов»), у всех пользователей повторяются одни и те же ходы (ночь, дофамин, пожарная сигнализация).
5. **Один вызов, без проверки и без постобработки.** Промпт просит «если фраза звучит как у любого психолога, перепиши» и «в готовом тексте пройдись и вычисти все "не X, а Y"», но второго прохода нет, а код ничего не чистит. Тире, «ё» и клише проходят в выдачу, если модель их допустила.
6. **Не определены пол и обращение.** Имя маскируется, поля пола нет, `appeal` не читается, системные промпты называют автора «он». Для аудитории, где почти все психологи женщины, это риск мужских форм от первого лица и плавающего «ты/вы» (в примерах рилс и плана «вы», в кабинете «ты»). Плюс анонимайзер превращает темы с «Любовь», «Надежда», «Вера», «Роман» в «[ИМЯ-1]».
7. **Генераторы не согласованы между собой.** Контент-план без профиля, паспорта, архетипа и анти-слопа, на «вы», с рубрикой «Истории», которая провоцирует выдумывать клиентов. Рерайт без архетипа. Карусель без стиля подхода. Хук и подсказка из плана теряются при генерации поста. Батчи плана не видят тем друг друга.
8. **Нет памяти о прошлых текстах.** История постов, избранное, исходники рерайта не используются ни как образцы, ни как «не повторяй заход». Голос не уточняется со временем, а обещание разбора архетипа («теперь посты будут собираться в твоем голосе») держится на 3-4 строках текста.
9. **Разные и абстрактные рамки хука.** В посте хук через узнавание и сцену; в хуках «Система 1 Канемана», «разрыв любопытства», 12 обязательных типов, включая «цифру» и «пост-диагностику»; в плане «2 секунды вызвать эмоцию» и FOMO. Типология из `ПРАВИЛА-ХУКОВ.md` (22 типа с механикой и выбором под площадку) не используется.
10. **Ресерч выдает «проверяемые» исследования и «точные цитаты» без веб-поиска.** Это не про голос, но это главный источник выдуманных фактов, которые потом идут в посты.

## 15. Найденные баги (попутно, код не трогала)

1. `generate-passport`: оси тона подписаны наоборот относительно UI и `profile-context.ts` (0 = «Формальный» в паспорте, 0 = «Разговорный» в UI).
2. `generate-content-plan`: `video_attitude === 'не снимаю'` не совпадает ни с одним реальным значением, reels всегда в плане.
3. Словари подходов: «Экзистенциальная терапия» из полного онбординга не матчится с ключом «Экзистенциальный», «Системная семейная терапия» без стиля.
4. `anonymize`: маскирует обычные слова-имена в теме и текстах («Любовь», «Надежда», «Вера», «Роман»), модель пишет по «[ИМЯ-1]».
5. План → пост: `hook` и `tip` дня не передаются в генерацию.
6. План: батчи не видят тем предыдущих батчей (возможны повторы).
7. `research-topics`: `passport.substring` без приведения к строке; лимит 3000 токенов на 30 тем с 9 полями на грани обрезки JSON.
8. Тест-архетип при повторном прохождении дописывает ответы в `live_voice` снова, поле растет дублями.
9. Промпты требуют «е» вместо «ё», но сами содержат «ё» (profile-context, паспорт, research).
