## Контекст

PsyCont: русскоязычный AI-сервис, который пишет инстаграм-контент за психологов их голосом. Стек: Next.js 15, React 19, Tailwind 4, Supabase, прямой OpenAI (модель gpt-5.4) через `generateWithAI` в `lib/openrouter.ts` (название файла историческое, OpenRouter не используется). Сервер VPS, на нем же живет другой проект Razbor, его процессы не трогать никогда.

Проблема: генератор пишет безлико и одинаково у всех психологов. Мы провели большую работу и спроектировали новый «мозг» генератора. Все материалы лежат в репозитории в папке `_знания/мозг-генератора/`:
- `01-KARTA-SMYSLOV.md`: 14 смыслов поста (что пост дает читателю), состояния читателя, красные линии этики. Прочитай целиком, это логика продукта.
- `02-ARHITEKTURA.md`: новая цепочка генерации, слои данных о психологе, параметры модели, известные баги. Прочитай целиком.
- `03-PROMPTY.md`: точные тексты всех промптов (П0 слепок голоса, П1 план, П2 текст, карточки смыслов и форматов, П3 проверка кодом, П4 проверка моделью с П4-мини, П5 правка, П6 три других хука). Это главный файл. Тексты промптов переносить в код ДОСЛОВНО, ничего не «улучшать» и не сокращать: каждая фраза там появилась после тестов.
- `04-TESTY.md`: как промпты тестировали и что нашли.
- `05-NAHODKI-TG.md`: что взято из чужих каруселей и рилсов (новые подачи в промптах 3.4, стили каруселей). Для этого этапа только для понимания.
- `code/text-guard.ts` и `code/test-guard.mts`: готовый и проверенный код шага П3 (автозамены, находки, память о заходах). Перенести как есть.

Коротко, что меняется. Сейчас генерация поста это один вызов модели с урезанным до 800 символов паспортом. Новая цепочка:
1. П1 план (JSON): смысл, состояние читателя, одна мысль, перевод терминов, хук, дуга, деталь, финал, риски; если для смысла нужен материал психолога, которого нет, план возвращает вопрос психологу и запасной смысл.
2. П2 текст свободным текстом: слепок голоса + 3 образца + настройки + карточка смысла + карточка формата + план + память.
3. П3 код: `autofix` и `guard` из `text-guard.ts`.
4. П4 проверка моделью (JSON), серьезность ok / zamechaniya / oshibki / perepisat.
5. П5 точечная правка по находкам или повторный П2 при perepisat.
6. П4-мини и П3 по измененным кускам, максимум две правки, в конце `finalNet`.

## Что сделать на этом этапе

Только генератор поста (`app/api/generate-post`) и все, что ему нужно. Карусели, рилсы, хуки и контент-план переводим следующими этапами, их не трогай.

0. **Сначала сохрани материалы в git.** Папка `_знания/мозг-генератора/` положена в репозиторий, но еще не закоммичена. Проверь `git status`, закоммить эту папку отдельным коммитом («Мозг генератора: карта смыслов, промпты, тесты») и запушь, до любых изменений кода.

1. **Модуль генерации** `lib/generation/`:
   - `text-guard.ts` из `_знания/мозг-генератора/code/` без изменений, плюс тест (перенеси `test-guard.mts` в формат тестов проекта или оставь скриптом, который запускается через node);
   - `prompts.ts`: все промпты и карточки из `03-PROMPTY.md` как строковые константы и функции сборки пользовательских промптов. Дословно. Плейсхолдеры `{{...}}` заменяются кодом; пустые поля не выводятся (так сказано в документе);
   - `pipeline.ts`: цепочка П1 → П2 → П3 → П4 → П5 → П4-мини → finalNet по правилам раздела «Что делает код с результатом» в `03-PROMPTY.md`;
   - `memory.ts`: сбор памяти из последних 10 постов психолога (коды хуков, дуги, первые строки через `extractOpening`, финалы, ring, смыслы, фразы клиентов, детали, фирменные обороты через `findSignatures`, темы, причины «Не похоже на меня», если они уже есть в базе).
2. **Данные.** Новая миграция в `supabase/migrations/` (файл создать, НЕ применять, применяю я). Посмотри текущие таблицы и существующие поля, не дублируй то, что уже есть (например, `appeal` уже есть и должен наконец использоваться для обращения ты/вы). Нужны:
   - в профиле: пол автора, аудитория, мат (нет / точечно), самораскрытие 1/2/3, как ко мне попасть, как проходит первая встреча, `voice_core` (текст слепка), образцы текстов (jsonb, с пометкой годности из слепка), фирменные обороты (массив), банк историй (jsonb: текст, уровень «личное / про работу / практика»), сквозной персонаж (текст, может быть пустым);
   - в `generated_posts`: смысл, код хука, дуга, тип финала, ring, первая строка, детали, использованная фраза клиента, использованные фирменные обороты, план (jsonb), результат проверки (jsonb), код формата.
   RLS как у соседних полей.
3. **Слепок голоса.** Эндпоинт, который собирает П0: берет образцы психолога (сначала `live_voice` из теста-архетипа как один образец, плюс тексты, которые психолог вставил сам), чистит `cleanSample`, вызывает П0, сохраняет слепок, годность образцов и фирменные обороты. Минимальный интерфейс в редактировании профиля: поле «Твои тексты» (вставить 3-5 своих постов) и кнопка «Обновить мой голос». Тексты интерфейса прогони через агента copywriter-psycont.
4. **Роут generate-post.** Новая цепочка включается флагом (переменная окружения и возможность включить для конкретного пользователя), по умолчанию выключена. Старый путь остается рабочим. Формат ответа для фронта не ломай; новые поля (смысл, вопрос психологу `need_detail`, заглушки `[добавь: ...]`) добавь рядом. Если `need_detail` не пустой, фронт показывает вопрос с кнопками «Ответить» и «Пропустить» (минимально, без редизайна экрана).
5. **Параметры модели.** Выясни по документации OpenAI и тестовым вызовом, принимает ли gpt-5.4 параметр `temperature` вместе с `reasoning_effort` (сейчас код передает temperature 0.7). Для шагов цепочки: `reasoning_effort: low`, `verbosity: low`. Покажи мне, что выяснил, до того как менять общий `generateWithAI`.
6. **Время.** Цепочка длиннее нынешнего таймаута 55 секунд. Сначала измерь на 3 тестовых вызовах. Если дольше 45 секунд, сделай так: текст после шага 2 возвращается сразу, проверка и правка идут фоном, фронт подменяет текст, когда правка готова (с тихой пометкой). Предложи мне способ до реализации.
7. **Баги из `02-ARHITEKTURA.md`, которые мешают новой цепочке:** анонимайзер маскирует обычные слова «Любовь», «Надежда», «Вера», «Роман» в теме и текстах; в промптах нет пола автора и не используется `appeal`. Остальные баги из списка не трогай на этом этапе, только перечисли их в отчете.
8. **Тестовый прогон на настоящей модели.** В `_знания/мозг-генератора/test/PERSONY.md` лежат три тестовых психолога и 12 тем. ПЕРЕД запуском скажи мне примерную стоимость в рублях и дождись моего «да»: это настоящие деньги.

## Правила проекта (из CLAUDE.md, соблюдать)

- Весь текст для пользователя по-русски, на «ты», женский род, без тире, «е» вместо «ё», без канцелярита и ИИ-клише, слово «энергия», не «кредиты».
- Обязательные агенты: backend-psycont для серверной части и миграции, reviewer-psycont перед коммитом, copywriter-psycont для любых текстов интерфейса, designer-psycont если трогаешь экран. Бренд: крем #F7F3EC, индиго #2E2A45, аметист #5B4FA0, без красного.
- Мобильная проверка любого экрана, который трогаешь.
- После работы допиши в CLAUDE.md в журнал тех-ловушек коротко: новая цепочка генерации, где лежит, как включается флаг, что проверено.
- Коммиты небольшими шагами, сообщения по-русски в стиле существующих коммитов.
