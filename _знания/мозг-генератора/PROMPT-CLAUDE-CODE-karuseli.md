## Контекст

PsyCont: русскоязычный AI-сервис, который пишет инстаграм-контент за психологов их голосом. Стек: Next.js 15, React 19, Tailwind 4, Supabase, прямой OpenAI через `generateWithAI` в `lib/openrouter.ts` (название историческое). Сервер VPS, на нем же живет другой проект Razbor, его процессы не трогать никогда.

На этапе 1 в `lib/generation/` появилась новая цепочка генерации (план П1, текст П2, проверка кодом П3, проверка моделью П4, правка П5) и она включена для поста через флаг. Сейчас делаем карусели на той же цепочке и два вида оформления:
- **шаблонные**: текст верстается в один из 4 готовых стилей, можно со своими фото;
- **с картинками**: нейросеть рисует картинки на часть слайдов в одном из 3 стилей, текст кладется поверх версткой.

Документы в `_знания/мозг-генератора/`:
- `07-KARUSELI-TZ.md`: главное ТЗ этого этапа. Экран, промпт П7 (раскладка текста по макету), 7 стилей с точными шрифтами, цветами и размерами, промпты картинок, стоимость, рендер, хранение, проверки. Прочитай целиком.
- `03-PROMPTY.md`: промпты цепочки, карточка формата `carousel`, кнопки «Поправить». Формат carousel уже описан, его не меняем.
- `05-NAHODKI-TG.md`, раздел 3: откуда взялись стили (для понимания).
- `02-ARHITEKTURA.md`: цепочка и таймауты.

Текущий роут `app/api/generate-carousel/route.ts` работает на старом промпте. Старый путь оставляем рабочим.

- Весь текст для пользователя по-русски, на «ты», женский род, без тире, «е» вместо «ё», без канцелярита и ИИ-клише, слово «энергия», не «кредиты».
