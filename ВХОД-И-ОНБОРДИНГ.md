# ВХОД И ОНБОРДИНГ: задание на волну (финал)

**Статус: готово как задание на волну. Реализация по частям, когда дойдут руки.**

Финальный документ-задание на волну «вход и онбординг»: демо на лендинге, регистрация, быстрый путь до первого поста, апселл распаковки, распаковка голосом. Все развилки закрыты, видение собрано в цельный поток. Часть 1 это готовое видение под реализацию. Часть 2 только то, что сознательно вынесено в будущее. Часть 3 сводка принятых решений. Часть 4 техника и риски. В конце короткий список новых вопросов к подтверждению, которые всплыли при финальной шлифовке.

Документ собран с двумя агентами: designer-psycont (анимации, дизайн, ТЗ перехвата) и product-kritik (логика потока). Их доводки вшиты в согласованное.

**Сквозной принцип.** Показывать результат, а не фичи. Не заставлять, а вести (даже на нижнем уровне продукт ведет, а не бросает в пустой экран). Дать выбор после того, как ценность почувствована, а не на двери. Момент ценности (первый готовый пост в голосе психолога) к 2-5 минутам. Тон без давления и urgency, без тире, буква е вместо ё во всех видимых текстах.

**Целевой человек.** Психолог 2-5 лет практики, пробовал вести блог, отклика не было, клиентов из блога нет. Скептик, видел десятки красивых генераторов, верит не результату, а причине. Весь вход говорит с ним одним.

# Часть 1. ВИДЕНИЕ И ПОТОК (финал)

## 1. Цель входа

Человек заходит на лендинг, видит ценность глазами (демо), вкладывает свою мысль прямо в демо, регистрируется в один тап, сразу получает первый готовый пост в своем голосе. Это момент ценности. Только после того, как вау почувствован, продукт предлагает углубиться (распаковка голосом), чтобы дальше темы и план приходили сами.

Вход продает не скорость и не красоту (красивых генераторов он видел), а узнавание: вот так выглядит текст, который не палится как нейросеть, поэтому его дочитывают. Отстройку от ChatGPT держим словами рядом с демо (подзаголовок, FAQ), не внутри самого демо: демо показывает нашу магию, а не чужую слабость.

## 2. Сквозной поток (end-to-end)

```
ЛЕНДИНГ
  Hero (обещание словами)
  ДЕМО (одно превращение: сырая мысль вымышленного психолога → готовый пост)
     │
     ├─ человек кликает в демо → перехват → поле становится живым
     │     печатает или надиктовывает СВОЮ мысль → жмет «сделать пост»
     │           │
     │           └─ AuthModal (контекст: заведем кабинет, чтобы собрать твой пост)
     │                 регистрация Яндекс ID в один тап
     │                 мысль прокинута через localStorage
     │
     └─ человек вошел НЕ через демо (кнопка в шапке, CTA внизу, прямая ссылка)
           регистрация → у него нет готовой мысли

ПОСЛЕ РЕГИСТРАЦИИ → БЫСТРЫЙ ПУТЬ (дефолт, первый пост)
  Экран первого поста, НИКОГДА не пустой:
    слева мысль (из демо, либо предзаполненный пример + чипы-затравки)
    тумблер площадки (инста / телеграм, дефолт инста)
    → генерация → готовый пост в его голосе (реальный стрим), без объяснений

  ПОСЛЕ ПОСТА (вау почувствован):
    заметная карточка-апселл «настроить голос» (распаковка голосом)
       ├─ согласился → РАСПАКОВКА ГОЛОСОМ (путь Б)
       └─ пока сам → остается на быстром пути, ведение сохраняется

ВТОРОЙ ПОСТ (и без распаковки)
  контент-план предлагает готовые темы-затравки (никогда не пустой экран)
  напоминание про распаковку всплывает по месту трения, не по таймеру
```

## 3. Демо на лендинге (десктоп)

Интерактивный мокап с анимацией движения. Не скриншот и не видео, живая CSS/JS анимация. Одно сильное превращение: сырая мысль психолога в готовый пост в его голосе. Пример на вымышленном психологе, это честно.

**Где живет.** Сразу после Hero, отдельной секцией, перед блоком болей.

**Заголовок секции:**
- надзаголовок аметистом: «Как это работает»
- H2: «Одна мысль вслух. И готовый пост в твоем голосе.»
- подзаголовок (отстройка от ChatGPT словами): «Не безликий текст из нейросети, который листают мимо. Живой пост, который звучит как ты, поэтому его дочитывают.»
- дисклеймер под демо (честно, без звездочек): «Пример работы движка. Твой пост соберется в твоем голосе, на твоей мысли.»

**Раскладка.** Одна рабочая поверхность, мини-версия реального генератора (узнаваемо и честно). Левая зона ~40% сырье, правая ~58% результат. Контейнер max-width ~1040px по центру.

```
 ┌──────────────────────────────────────────────────────────────┐
 │  ЛЕВАЯ ЗОНА ~40%             │   ПРАВАЯ ЗОНА ~58%              │
 │  ярлык: «ваша мысль»         │   ┌──────────────────────────┐ │
 │  ┌────────────────────────┐  │   │  готовый пост (карточка) │ │
 │  │ клиенты часто стыдятся │  │   │  Плакать тут не стыдно   │ │
 │  │ плакать у меня на      │  │   │  ~~~~~ (squiggle)        │ │
 │  │ сессии▌                │  │   │  Почти каждый, кто...    │ │
 │  └────────────────────────┘  │   └──────────────────────────┘ │
 │   ┌──────────────────────┐   │     [попробовать со своей     │ │
 │   │  ✶ сделать пост      │ → │      мыслью →]                 │ │
 │   └──────────────────────┘   │                                │ │
 └──────────────────────────────────────────────────────────────┘
```

**Контраст материалов несет смысл превращения.** Слева черновик: поле мысли на мягкой лавандовой подложке #EFEBF7, rounded-3xl, ощущение «вмятины в столе». Справа чистовик: карточка поста чистая белая, rounded-3xl, теплая мягкая тень (индиго ~8%, не серая). Зернистость только на фоне секции, карточка поста гладкая. Превращение читается даже на стоп-кадре.

**Цвета по элементам.** Кнопка «сделать пост»: аметист #5B4FA0, белый текст, rounded-2xl, иконка-искра шалфея. Каретка печати: аметист, мигает. Заголовок поста: индиго #2E2A45, под ним Squiggle шалфея. Тело поста: приглушенный индиго, leading-relaxed. CTA под постом: вторичная кнопка (контур аметиста). Один акцент аметист, шалфей только на деталях. Без градиента и второго яркого цвета.

**Брендовый курсор**, не системная стрелка. Скругленный лепесток-указатель, индиго со светлой обводкой цвета бумаги, ~22px, теплая тень. За курсором еле заметный хвост-послесвечение лаванды. В момент клика из-под кончика расходится кольцо шалфея (scale 0 в 1.8, opacity 1 в 0, ~350мс).

**Дуга-связка шалфея** между сырьем и постом: рисуется в момент клика тем же pathLength, что Squiggle. Усиливает «вот отсюда родилось вот это».

**Хореография по фазам.** Базовая кривая раскрытия `cubic-bezier(0.22, 1, 0.36, 1)` (как в существующем Squiggle), движение курсора `cubic-bezier(0.45, 0, 0.25, 1)`.

| Фаза | Время | Что происходит |
|---|---|---|
| 0. Покой | 0–500мс | поле пустое, бледный плейсхолдер, курсора нет |
| 1. Печать мысли | 500–4100мс | ~58мс/символ с мягким джиттером, микропауза на запятой, каретка мигает |
| 2. Чтение | 4100–4850мс | текст застыл, пауза дать прочесть |
| 3. Курсор едет к кнопке | 4850–5700мс | появляется у конца текста, едет по легкой дуге, хвост-послесвечение |
| 4. Наведение | 5700–5850мс | кнопка чуть темнеет, поднимается на 1px |
| 5. Клик | 5850–6150мс | микро-кивок курсора, кнопка scale 0.96 в 1, кольцо-импульс шалфея |
| 6. Подумать | 6150–6800мс | на кнопке три пульсирующие точки шалфея, курсор уходит и гаснет |
| 7. Пост разворачивается | 6800–7350мс | контейнер раскрывается от кнопки (height auto + opacity + scale 0.98 в 1), тень растет, рисуется дуга-связка |
| 8. Заголовок | 7350–7900мс | проявляется словами, под ним рисуется Squiggle |
| 9. Тело по словам | 7900–11800мс | слова появляются по очереди (opacity + translateY 4px), абзацы с микропаузой. НЕ посимвольно (нервно и дешево), пословно |
| 10. CTA | 11800–12500мс | под постом fade-up вторичной кнопки |
| 11. Чтение | 12500–17500мс | все стоит, можно прочитать пост целиком |
| 12. Мягкий сброс | 17500–18300мс | пост плавно гаснет, возврат к фазе 0 |

Полный цикл ~18с, самое ценное (печать мысли + разворот) в первые ~12с.

**Цикл и вьюпорт.** Анимация идет только пока блок во вьюпорте (IntersectionObserver). Цикл максимум 1-2 раза, затем замирает на результате (готовый пост + CTA). Под полем маленькая ссылка «показать снова». Без вечного автоповтора и без резкого обрыва на сбросе.

**Доступность.** При `prefers-reduced-motion: reduce` никакой анимации: сразу финальное статичное состояние (мысль слева, готовый пост справа, оба видны), Squiggle статичный. Декоративные элементы (курсор, каретка) aria-hidden, для скринридера текстовая суть и сам текст поста.

**Текст поста для демо (образец, в голосе вымышленного психолога).** Заголовок «Плакать тут не стыдно», под ним Squiggle. Тело:

> Почти каждый, кто впервые плачет на сессии, потом извиняется. Будто слезы это что-то, что надо быстро убрать со стола.
>
> Я смотрю иначе. Слезы приходят, когда внутри стало достаточно безопасно, чтобы перестать держать оборону хотя бы на минуту.
>
> Если рядом со мной вам захотелось плакать, значит, доверие уже началось. И мы уже работаем.

Сцена с первой строки, от первого лица, без «это не про X, это про Y», без приклеенного CTA.

## 4. Демо на мобилке (360–390px)

То же превращение, вертикально. Курсор заменяется на индикатор тапа. На мобилке НЕ автозапуск.

**Вертикальная раскладка.** Сверху вниз: заголовок, поле мысли, кнопка, разворот поста ниже. В первый экран влезает мысль + кнопка, над сгибом выглядывает верхний краешек будущей карточки поста (2-3мм) как обещание. Когда пост разворачивается, страница сама плавно подскролливает к нему (scrollIntoView smooth).

```
 ┌─────────────────────────┐
 │  Как это работает        │
 │  Одна мысль. Готовый пост│
 │  (подпись про пример)    │
 │ ┌─────────────────────┐  │
 │ │ клиенты часто        │  │  ← поле, превью-вид (не активный инпут)
 │ │ стыдятся плакать▌    │  │
 │ └─────────────────────┘  │
 │ ┌─────────────────────┐  │
 │ │   ✶ сделать пост    │  │  ← кнопка, ~75-80% высоты экрана
 │ └─────────────────────┘  │
 │ [ Вписать свою мысль ]   │  ← явная точка перехвата (см. раздел 5)
 │ ─ ─ ─ краешек поста ─ ─  │  ← линия сгиба
 └─────────────────────────┘
```

**Индикатор тапа** вместо курсора. Полупрозрачный круг лаванды #E7E2F2, ~46px, обводка аметиста. Появляется над кнопкой, плавно опускается на нее (~500мс), будто палец заходит сверху. Нажатие: круг сжимается до ~36px, кнопка scale 0.96, из-под круга кольцо шалфея. Движение только вертикальное.

**Тайминг короче:** печать ~2.6с, чтение 500мс, тап ~650мс, точки 500мс, разворот с автоскроллом ~600мс, текст по словам ~2.8с, чтение финала 4с. Полный цикл ~12.5с, один прогон, потом замирает.

**Запуск только по тапу или доскроллу** (не на загрузке): первый кадр статичный с видимым контентом, печать стартует по тапу области демо или по попаданию во вьюпорт (порог ~0.5). Reduced-motion: статичная финальная композиция.

## 5. Перехват демо в живой ввод (ТЗ, designer-psycont)

Демо это первый шаг воронки. Любой клик в демо отдает поле человеку, его мысль прокидывается в онбординг.

**Стейт-машина** (явный стейт, не выводить из таймеров): `demoMode: 'auto' | 'intercepting' | 'live'`. Из `live` назад в `auto` в этой сессии не возвращаемся (иначе у человека уедет текст).

**Что кликабельно (десктоп).** Оба элемента ведут в `live`: поле мысли (вся подложка, при ховере чуть светлеет, снизу бледная подпись «можно вписать свою мысль») и кнопка «сделать пост» (в режиме `auto` клик по ней НЕ запускает фейк-генерацию, а переводит в `live` и ставит фокус в поле, кнопка работает только над реальным текстом). Клики по заголовку, подписи, ссылке «показать снова» перехват не запускают.

**Момент перехвата** (плавно, не дергано, ~280мс): останавливаем таймеры хореографии; курсор и кольцо гаснут (opacity в 0, scale в 0.9, 180мс); если справа уже частично проявился демо-пост, он сворачивается (opacity и height в 0, 220мс), дуга гаснет; поле получает focus-обводку аметиста, декоративная каретка убирается, ставится реальная; фокус в textarea.

**Демо-текст мысли стирается, но переезжает в placeholder** (не остается реальным значением, человек пишет с чистого листа, не стирает чужое). Если перехват случился до конца печати, в placeholder кладем полную эталонную фразу, не обрезок.

**Живое поле (`live`):** textarea на лавандовой подложке #EFEBF7, rounded-3xl, Onest, размер ≥16px (iOS не зумит), авто-рост (min ~3 строки, max ~8). Placeholder эталонная мысль бледным. В правом нижнем углу иконка-микрофон (надиктовать мысль, тот же свой Whisper; если запись не успевают в волну, иконка остается с мягкой плашкой «голосовой ввод скоро», место заложить сразу). Надиктовка короткой мысли бесплатна, энергией не метрится (это вход, самая массовая точка, брать энергию за первую мысль = убить момент ценности). Мягкий лимит 600 символов (это мысль, не пост): счетчик появляется тихо после 480, на 600 ввод стоп и спокойная строка «Этого хватит, дальше PsyCont развернет сам». Без красного и тряски. Подпись честности меняется на «Это уже про вас. Впишите мысль, дальше превратим в пост.»

**Кнопка «сделать пост» в `live`** (реальный submit): при пустом поле приглушена и не кликается (без ошибки заранее); при наличии текста активна (легкий fade насыщенности как тихая награда). Клик не запускает генерацию (человек не залогинен): сначала сохраняем мысль, потом открываем AuthModal.

**Что по клику:**
1. Сохраняем мысль в localStorage (раздел ниже) ДО открытия модалки, чтобы потеря была невозможна.
2. Открываем существующий AuthModal в режиме register, с новым опциональным пропом `contextNote`. Копия: «Заведем кабинет, чтобы собрать твой пост и он не потерялся. Вход через Яндекс, один тап.» (генерация ПОСЛЕ регистрации, поэтому копия про мысль, не про готовый пост, см. вопрос 1 в конце).
3. Дальше AuthModal как есть, после успеха ведет на онбординг (логику редиректа не трогаем).

**Граничные случаи:** пустое и только-пробелы (trim, кнопка неактивна); длинный ввод режется на 600; **человек закрыл модалку не зарегистрировавшись** мысль не теряем (поле заполнено, один раз мягко всплывает «Ваша мысль на месте. Зарегистрируйтесь, и мы сразу сделаем из нее пост.»); двойной клик дебаунсим.

**Механизм передачи мысли (рекомендация designer).** Яндекс OAuth полностью выгружает страницу (редирект на oauth.yandex.ru и назад), email-подтверждение открывает онбординг отдельным переходом, поэтому React-стейт и URL не переживут. Единственный надежный носитель через все ветки это **localStorage**: ключ `psycont_seed_thought`, значение `{ text, ts }`, TTL 24 часа. Пишем при клике «сделать пост» (до модалки). Читаем в онбординге при монтировании: если свежий, подставляем в стартовое поле быстрого пути как редактируемое значение, после потребления удаляем. Не URL (утечка персданных + не переживет OAuth), не React-context (не переживет выгрузку).

**Мобилка, развязка тапа.** Один тап не должен значить сразу «запусти анимацию» и «отдай ввод». Первый тап области демо = запуск анимации (поле в этот момент readonly-обертка, не открывает клавиатуру). Перехват отдельной явной кнопкой **«Вписать свою мысль»** (контур аметиста) под полем, тап по ней в `live` (textarea, фокус, клавиатура). После того как демо отыграло, «Вписать свою мысль» становится главным акцентом блока.

## 6. Первый пост (быстрый путь, дефолт)

После регистрации человек попадает на экран первого поста. Он **никогда не пустой** (иначе на самой массовой двери воспроизводим ту самую боль пустого экрана).

**Если пришел из демо-перехвата:** его мысль уже стоит в поле слева.

**Если пришел НЕ через демо** (кнопка в шапке, CTA внизу, прямая ссылка): поле предзаполнено редактируемой мыслью-примером плюс 3-4 чипа-затравки «или начни с этого». Затравки это узнаваемые темы из практики психолога (собранные по типовым болям из банка болей, поданные как «о чем написать», а не как клиентская жалоба и не как «твоя мысль»). Тап по чипу подставляет тему в поле, ее можно править, печатать свою или надиктовать.

Формулировка экрана:
> С чего начнем твой первый пост. Напиши или скажи мысль из практики, и я соберу из нее пост в твоем голосе.
> _чипы:_ или начни с этого: «клиенты часто стыдятся плакать у меня на сессии» · «многие приходят с запросом не про то, что болит на самом деле» · «вина за время на себя»

**Тумблер площадки** мягко на этом же экране: маленький тумблер прямо на экране поста, один тап, дефолт инстаграм, телеграм вторым. НЕ отдельный экран-анкета. Формат первого поста зависит от площадки (инста и ТГ разводятся в правилах).

**Генерация после регистрации** (не тратим AI на анонимов): реальный стрим OpenAI через существующий `lib/sse-stream.ts`. Промпт быстрого пути жестко тянет правила хуков (сцена с первой строки, узнавание, без объявления темы, без приклеенного CTA) даже на тонком входе без профиля. Первый пост обязан быть хорошим, это самый хрупкий момент, проверять на живых прогонах до релиза.

**Преемственность вида** (демо ↔ первый пост): тот же двухзонный вид, слева мысль на лавандовой «вмятине», справа пост на белой карточке, та же хореография разворота (заголовок, Squiggle, тело по словам), та же дуга-связка. Человек видит свой текст ровно там, где в демо была мысль вымышленного психолога. Демо это трейлер той же сцены, первый пост сама сцена с его именем. Заголовок экрана в том же регистре: «Ваша первая мысль стала постом».

**Без объяснений в эту волну.** Первый пост идет просто как хороший пост, без строки-мостика и без разбора. Объяснялку «почему такие посты работают» не дробим: и легкая строка-мостик, и полный персональный разбор «почему именно твои прошлые посты не залетали» идут одной следующей волной (Часть 2). В эту волну первый пост должен быть просто сильным сам по себе.

**Отказоустойчивость.** Если генерация упала (server_error), мягкая плашка ServerErrorNotice с повтором, мысль не теряется. Это не теория, на проде уже был ложный server_error из-за сломанного service_role.

## 7. Апселл распаковки после первого поста

Только после того, как первый пост готов и вау почувствован. **Не модалка поверх поста** (это давление и крадет вау), а заметная теплая карточка ПОД постом (лавандовая плашка, аметистовая кнопка), весомая по виду, но не перехватывает управление.

Формулировка от результата, без urgency:
> Первый пост уже звучит как ты. Хочешь, чтобы дальше темы и план приходили сами, под твою нишу и твоих клиентов, и не надо было придумывать с нуля каждый раз. Расскажи о себе голосом, это пара минут.
> _кнопка:_ Рассказать о себе · _вторичная:_ Пока попробую сам

**Если проигнорировал:** не напоминать по таймеру и не догонять попапами (это нарушит «без давления»). Постоянный тихий вход остается в доме (мягкая карточка «настроить голос» без счетчика заполненности и без вины). Повторное предложение привязано к моменту трения, а не ко времени: когда человек идет за вторым постом, по месту всплывает строка «Чтобы темы приходили сами под твою нишу, расскажи о себе. А пока вот пара тем на пробу.»

## 8. Распаковка голосом (путь Б, для согласившихся)

Вместо 22 текстовых вопросов AI ведет разговор как живой человек-маркетолог. Психолог наговаривает голосом истории и специфику. Ощущается как тест-знакомство, не анкета. Голосом человек выдает в 3 раза больше своих слов.

**Формат: свободный монолог плюс уточнения** (не диалог по одному вопросу, иначе латентность транскрибации рвет ощущение живого разговора). Психолог наговаривает про себя свободно 2-3 минуты, потом AI задает пару адаптивных уточнений по сказанному.

**Как устроено по шагам:**
1. Запись голоса в браузере (MediaRecorder).
2. Аудио на сервер, транскрибация своим Whisper через ffmpeg (НЕ Supadata, она только для видео по ссылке).
3. Аудио удаляется сразу после транскрибации, хранится только текст (снимает основной риск с биометрией, см. Часть 4).
4. AI читает расшифровку, задает пару уточнений, собирает профиль голоса.

**Требования:**
- Текстовый фолбэк виден на каждом шаге, не спрятан (микрофон могут не дать, человек в кафе, не готов говорить вслух). Голос рекомендуемый путь, не единственный.
- Интервью ведет психолога говорить про СЕБЯ (путь, подход, на чем горит, чем отличается), про клиентов только обобщенно (этический барьер: психолог не имеет права рассказывать про клиентов).
- В начале честная строка про приватность: голос используем только чтобы расшифровать в текст, аудио удаляем сразу, храним только обезличенный текст, все в России.
- Первый вопрос теплый и легкий, чтобы человек заговорил. Можно перезаписать ответ.

## 9. Передача в контент-план (второй пост без трения)

Активация это не один вау-пост, North Star это 4+ поста в месяц. После первого поста продукт ведет дальше, **даже без распаковки**, просто грубее по персонализации, а не отсутствием ведения.

Контент-план никогда не дает пустой экран. На чем строит темы без распаковки: площадка, факт что это психолог, первая мысль и первый пост (сигнал темы), банк болей и банк форматов. Предлагает несколько готовых тем-затравок: часть из типовых болей, часть как смежные углы к мысли, которую человек только что использовал.

Честная развилка двух уровней (она же делает апселл правдивым):
- Без распаковки: темы все равно приходят, но более общие, по типовым болям и по первой мысли. Пустого экрана нет.
- С распаковкой: темы и план точнее под нишу, подход и аудиторию, продукт строит план, а не просто список.

Жесткое правило: не выпускать быстрый путь со вторым экраном «придумай мысль сам». Обещание «продукт ведет» держится и на нижнем уровне.

## 10. Регистрация

Максимально короткий вход на пике интереса: **Яндекс ID в один тап** (полный редирект, уже в коде). Email с подтверждением по ссылке убивает момент, поэтому если человек идет через email, дать увидеть первый пост, а подтверждение почты сделать мягким и отложенным, не стеной перед ценностью.

**Возврат уже зарегистрированного.** Если человек с готовым профилем снова кликает демо-CTA, вести в дашборд, не в онбординг и не в первый пост заново (на проде были петли онбординга, не повторять).

## 11. Тексты входа (финальные формулировки)

Все без тире и без буквы ё, проверено.

- H2 секции демо: «Одна мысль вслух. И готовый пост в твоем голосе.»
- Подзаголовок (отстройка): «Не безликий текст из нейросети, который листают мимо. Живой пост, который звучит как ты, поэтому его дочитывают.»
- Дисклеймер демо: «Пример работы движка. Твой пост соберется в твоем голосе, на твоей мысли.»
- FAQ-блок отстройки: «Чем это отличается от ChatGPT. ChatGPT пишет гладко и одинаково для всех, такой текст видно и его листают. PsyCont учится на твоем голосе и пишет как живой психолог, а не как нейросеть. Поэтому посты звучат как ты и их дочитывают.»
- AuthModal contextNote: «Заведем кабинет, чтобы собрать твой пост и он не потерялся. Вход через Яндекс, один тап.»
- Экран первого поста: «С чего начнем твой первый пост. Напиши или скажи мысль из практики, и я соберу из нее пост в твоем голосе.»
- Апселл: «Первый пост уже звучит как ты. Хочешь, чтобы дальше темы и план приходили сами, под твою нишу и твоих клиентов, и не надо было придумывать с нуля каждый раз. Расскажи о себе голосом, это пара минут.»

## 12. Почему так (обоснование, для команды, не на витрину)

- Интерактивное демо до регистрации повышает активацию: ценность глазами раньше слов.
- Голосовое интервью дает завершаемость выше, чем формы, и в 3 раза больше живой речи. Оговорка: цифры про опросы вообще, у осторожной аудитории с барьером приватности реальный показатель ниже, не закладывать как обещание себе.
- Дефолт плюс апселл после вау снимает paradox of choice (выбор после ценности, а не на двери).
- Каждая лишняя минута до ценности снижает конверсию, момент ценности к 2-5 минутам.
- Цифры не тащить на лендинг (правило про фейк-статистику), это обоснование для команды.

# Часть 2. К БУДУЩЕМУ ОБСУЖДЕНИЮ (вынесено из этой волны)

**Объяснялка «почему пост работает» (целиком, не дробя).** Идет одной следующей волной сразу после этой, двумя уровнями вместе: легкая строка-мостик под постом («пост начинается со сцены узнавания, а не с объявления темы, поэтому такие дочитывают») и полный персональный разбор «почему именно твои прошлые посты не залетали» (хук объявлял тему, текст звучал как нейросеть, и почему этот сработает). Бьет ровно в боль «клиентов нет, не понимаю что не так», превращает вход из «вот тебе пост» в «вот почему этот приведет людей». Вынесено сознательно: меняет вывод генерации, крупнее flow-правок, и дробить объяснялку на части неправильно. В эту волну первый пост идет без объяснений, просто хороший пост сам по себе.

**Голосовой ввод мысли на быстром пути (надиктовка короткой мысли).** Если запись микрофона не успевают в эту волну, место под иконку-микрофон в живом поле и на экране первого поста закладывается сразу, сама надиктовка может прийти следующим шагом.

# Часть 3. ПРИНЯТЫЕ РЕШЕНИЯ (сводка развилок)

1. **Демо: одно превращение** (мысль в пост), не контраст с ChatGPT. Отклонено сознательно: демо показывает нашу магию, а не чужую слабость. Отстройка от ChatGPT словами рядом (подзаголовок, FAQ).
2. **Путь А: первый пост из сырой мысли** психолога (текст или голос), не «грубее по тону». Пост звучит как он сразу, потому что построен на его словах. Распаковка нужна не чтобы голос стал живым, а чтобы продукт сам предлагал темы и план.
3. **Развилка заменена на дефолт плюс апселл.** Дефолтный быстрый путь, предложение распаковки после первого поста, заметное (карточка под постом), не спрятанное.
4. **Интервью: свободный монолог 2-3 минуты плюс пара уточнений**, не диалог по одному вопросу (латентность транскрибации).
5. **Перехват демо в живой ввод принят** как обязательный (демо первый шаг воронки, мысль через localStorage в онбординг).
6. **Подняты в согласованное:** контраст материалов, демо только во вьюпорте, дуга-связка шалфея, на мобилке не автозапуск, передача в контент-план после первого поста, короткая регистрация Яндекс ID, честный дисклеймер про пример.
7. **152-ФЗ:** аудио удаляем сразу после транскрибации, храним только текст.
8. **Первый экран быстрого пути никогда не пустой** (мысль из демо либо пример плюс чипы-затравки), тумблер площадки на нем же.
9. **Генерация первого поста после регистрации** (не тратим AI на анонимов). Регистрация в один тап Яндекс ID, сразу пост, момент ценности не страдает.
10. **Контент-план ведет и без распаковки** (темы-затравки, никогда не пустой экран).
11. **Тумблер площадки мягко на экране поста** (маленький, один тап, дефолт инстаграм, не отдельный экран-анкета).
12. **Надиктовка короткой мысли на быстром пути бесплатна**, энергией не метрится (вход, массовая точка). Длинное интервью-распаковка учитывается отдельно, можно метрить если понадобится. Совпадает с принципом «текст безлимит, энергия только на дорогое».
13. **Объяснялку «почему пост работает» не дробим и не берем в эту волну.** И легкая строка-мостик, и полный персональный разбор идут одной следующей волной. В эту волну первый пост без объяснений, просто хороший пост.

# Часть 4. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ И РИСКИ

Голосовое интервью и надиктовка самая тяжелая часть. Риски по убыванию:

- **152-ФЗ и приватность голоса.** Запись голоса фактически биометрия. Явное согласие до записи, свой Whisper (не запад), **аудио удаляется сразу после транскрибации, хранится только обезличенный текст**. Это снимает основной риск с биометрией. Зафиксировать как требование.
- **Этический барьер психолога.** Интервью ведет говорить про себя, про клиентов обобщенно, сказать про обезличивание. Иначе осторожный психолог бросит на первом вопросе.
- **Себестоимость транскрибации (разведено по решению).** Короткая надиктовка мысли на быстром пути бесплатна, энергией не метрится (вход, самая массовая точка, брать энергию за первую мысль = убить момент ценности; короткая мысль дешева). Длинное интервью-распаковка (2-3 мин) учитывается отдельно, можно метрить если на масштабе понадобится. Свой Whisper держит обе операции в РФ.
- **Латентность.** Поэтому интервью это монолог плюс уточнения, а не диалог по одному вопросу. Обработка должна быть приемлемой, иначе паузы рвут ощущение разговора.
- **Отказоустойчивость на пике интереса.** Падение генерации первого поста сразу после регистрации это мгновенный отвал на максимуме мотивации. Мягкая плашка ServerErrorNotice с повтором, мысль не теряется.
- **Текстовый фолбэк обязателен и видим** на каждом шаге интервью.
- **Неловкость говорить вслух.** Теплый легкий первый вопрос, возможность перезаписать.
